📦 Rules模块化规则（场景化配置）📘 核心价值
解决单一CLAUDE.md臃肿问题，按功能拆分专项规则（如code-style.md/testing.md）  
路径匹配机制：通过paths字段指定规则生效范围（如src/components/**/*.tsx），实现上下文按需加载，避免资源浪费

🚀 最佳实践
单一文件聚焦单一场景（如React组件规范独立成react.md）  
路径匹配语法同.gitignore（**/*.ts匹配所有TS文件）

🔧 Skills技能包（自动化工作流）📘 核心机制
自动触发：通过description字段定义触发条件（如&quot;当用户要求排版公众号文章时使用&quot;）  
渐进式披露：仅加载匹配技能的完整内容，支持同时安装20-50个技能而不占用过多上下文

🛠️ 制作流程（五步法）
场景识别：梳理重复工作流（如API创建/代码审查/公众号排版）  
文件夹创建：在.claude/skills/下建立技能目录（如wechat-format）  
SKILL.md编写：- Frontmatter：name（技能名）、description（触发条件）、allowed-tools（工具限制）- 正文：执行步骤（具体化操作）、踩过的坑（错误规避）、参考模板  
测试迭代：调整触发条件与执行步骤  
位置选择：项目级（团队共享）或全局级（个人通用）

📌 实战案例：公众号排版Skill---
name: 公众号排版助手
description: 当用户要求排版公众号文章、微信文章格式化时使用
allowed-tools: Read, Edit
---
## 执行步骤
1. 标题使用H2加粗（## 标题）
2. 正文每节不超过2句粗体文本
3. 表格替换为灰色section框
4. 结尾添加金句引用块（&gt; 金句内容）

## 踩过的坑
- 禁止用`&lt;font&gt;`标签设置字号
- 代码块与灰色框不可混用

🌐 MCP外部工具协议（能力扩展）📘 核心价值
突破本地限制：连接外部服务（搜索/浏览器/飞书等），实现从&quot;文件内助手&quot;到&quot;系统代理人&quot;的升级  
资源消耗：每个MCP占用10-20K tokens，需遵循按需安装原则

⚙️ Hooks自动化流程（安全与效率）📘 核心机制
事件触发：在特定操作前后自动执行预设动作（如代码修改后格式化）  
安全防护：通过PreToolUse Hook拦截危险操作（如删除.env文件）

🔥 必配钩子
自动Git存档：每步操作自动commit，支持回滚追踪  
代码格式化：调用Prettier/ESLint自动优化代码格式  
危险操作拦截：检查并阻断rm -rf等高危命令

🧠 Memory自动记忆（经验积累）📘 核心特性
自动记录：AI独立保存调试经验、编码偏好、项目坑点，存储于~/.claude/projects/&lt;项目路径&gt;/memory/  
智能加载：启动时加载最近200行关键记忆，不占用过多上下文  
个人专属：不进入Git，按项目隔离

⚖️ 与CLAUDE.md分工
CLAUDE.md：人工编写的规则与约定（团队共享）  
Memory：AI自动记录的经验与模式（个人专属）
