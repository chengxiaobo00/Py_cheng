## 介绍

* 一款开源、免费、全平台、好用好看的稍后读服务。
* Omnivore 是「杂食动物」、「杂食的人」的意思。名称有趣，阅读也应如此，杂食获取，再筛选咀嚼消化。

## 特点

* **免费、开源**。
* **设计现代，简约好看**。
* **稍后读功能**：支持保存网页链接、Newsletter 订阅、文档等内容。
* 支持**高亮**和**批注**。
* 支持**标签、过滤、高级搜索**等功能；
* 支持**全平台使用**。
* **文本转语音朗读**。支持中英文语言，支持人声和语速调整。声音效果自然逼真，使用体验很好。
* 直观的命令面板，使用快捷键触手可及。
* 支持与知识库和笔记软件等产品的**集成**。目前已经支持与 Obsidian、Logseq、Readwise 的内容集成，用户也通过触发 webhooks 实现软件数据互通。其中，Obsidian 插件暂时未上架社区插件市场，有需求可前往 [obsidian-omnivore](https://link.zhihu.com/?target=https%3A//github.com/omnivore-app/obsidian-omnivore) 下载。
* 支持 API Keys.

## 使用

* 邮箱注册登录，进入 Omnivore Library；
* **Add link**：点击复制粘贴网页链接；
* **浏览器插件**：点击插件图标进行剪藏；
* **移动端剪藏**：使用系统共享功能，点击分享按钮至 Omnivore 即可。

## 平台

跨平台使用。

* 基于网页端的 **PWA 应用**，在谷歌浏览器点击地址栏即可安装至桌面。
* **Apple 全平台**支持。
* 安卓版本还在内测。
