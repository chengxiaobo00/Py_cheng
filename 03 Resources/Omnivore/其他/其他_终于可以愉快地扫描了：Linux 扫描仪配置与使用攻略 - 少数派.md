值得一提的是，爱普生甚至还提供了 Epson Scan 2 的源代码，感兴趣的读者可以参考 AUR 上的 Epson Scan 2 软件包：https://aur.archlinux.org/packages/epsonscan2 。">1</sup>等极少数厂商外，很少有厂商会精心为 Linux 平台开发驱动程序与扫描软件。</p><p data-omnivore-anchor-idx="9">在政、企单位推动操作系统国产化进程的背景下，Linux 平台使用扫描仪的需求会越来越多，这无疑给运维人员出了一系列难题。同一台设备，要是偏偏在 Linux 下缺少软件而「趴窝」，那无疑会给单位的工作徒增不少麻烦。</p><p data-omnivore-anchor-idx="10">好在，这些问题都是可以化解的，Linux 发行版本身就有一套跨厂商的成熟解决方案——<strong data-omnivore-anchor-idx="11">SANE</strong>，满足你在 Linux 下扫描的刚需。</p><h3 data-omnivore-anchor-idx="12">1）基础设施：SANE</h3><p data-omnivore-anchor-idx="13">Linux 下，想用打印机，就找 CUPS；想用扫描仪，就找 SANE。</p><ul data-omnivore-anchor-idx="14"><li data-omnivore-anchor-idx="15"><strong data-omnivore-anchor-idx="16">关联阅读：</strong><a data-omnivore-anchor-idx="17" href="https://sspai.com/post/90194" target="_blank">终于可以在 Linux 下愉快打印了：Linux 发行版配置打印机攻略</a></li></ul><p data-omnivore-anchor-idx="18"><a data-omnivore-anchor-idx="19" href="https://sspai.com/link?target=http%3A%2F%2Fwww.sane-project.org%2F" target="_blank"><strong data-omnivore-anchor-idx="20">SANE</strong></a>（Scanner Access Now Easy，「扫描易」），是一套用于操作图像采集设备的标准化 API，为 UNIX / 类 UNIX 环境（例如 Linux 发行版）量身打造，可操作的设备包括扫描仪、相机、摄像头等。它是另一套图像采集标准 <a data-omnivore-anchor-idx="21" href="https://sspai.com/link?target=https%3A%2F%2Ftwain.org%2F" target="_blank">TWAIN</a> 的竞争对手<sup data-omnivore-anchor-idx="22" href="" footnote-id="2" data-title="TWAIN历史悠久，早在Windows 95时代就被Windows原生支持，参考C:\Windows目录下的“twain.dll”。但是，TWAIN对Linux的支持几乎为空白，不仅只能通过TWAIN Data Source Manager来连接网络扫描仪，而且还没有提供详实的官方文档。">2<div data-omnivore-anchor-idx="23"><p data-omnivore-anchor-idx="24">TWAIN历史悠久，早在Windows 95时代就被Windows原生支持，参考C:\Windows目录下的“twain.dll”。但是，TWAIN对Linux的支持几乎为空白，不仅只能通过TWAIN Data Source Manager来连接网络扫描仪，而且还没有提供详实的官方文档。</p></div></sup>。</p><p data-omnivore-anchor-idx="25">对于开发者来说，SANE 是一套通用的编程接口，适用于理论上所有的扫描仪，有助于简化扫描软件的开发工作，并提升用户的体验；对于一般用户来说，SANE 的意义更加显著——它担负着为各大 Linux 发行版提供扫描支持的使命，让你的扫描仪开箱即用，免去繁琐的配置。</p><h3 data-omnivore-anchor-idx="26">2）网络扫描协议：eSCL</h3><p data-omnivore-anchor-idx="27">熟悉 Linux 网络打印机配置的读者，会使用 IPP、LPD 这两种协议来连接网络打印机。而在扫描仪领域，也有着自己的「IPP」协议，那就是 eSCL（Extended Standard Client/Server Language，扩展标准下的客户端/服务端语言），又称为「AirScan」。这是由 <a data-omnivore-anchor-idx="28" href="https://sspai.com/link?target=https%3A%2F%2Fmopria.org%2F" target="_blank">Mopria 组织</a>开发的协议，基于 XML 与 HTTP。</p><p data-omnivore-anchor-idx="29">和 IPP 一样，使用 eSCL，你无须安装扫描仪驱动，就可以通过以太网、WLAN 和 USB 来连接扫描仪进行扫描。包括惠普、佳能、兄弟、爱普生在内的多家知名厂商都是 Mopria 组织的成员，其产品对该协议提供了完备支持。</p><h3 data-omnivore-anchor-idx="30">2）扫描软件</h3><p data-omnivore-anchor-idx="31">SANE 与 ESCL 本身属于基础设施，要想实现扫描功能，还需要相应的扫描软件。目前 Linux 平台下有两款免费、开源、实用的扫描软件，理论上适用于所有扫描仪，无须考虑各厂商各型号之间的差异。</p><ul data-omnivore-anchor-idx="32"><li data-omnivore-anchor-idx="33"><a data-omnivore-anchor-idx="34" href="https://sspai.com/link?target=https%3A%2F%2Fapps.gnome.org%2Fzh-CN%2FSimpleScan%2F" target="_blank"><strong data-omnivore-anchor-idx="35">Simple Scan</strong></a><strong data-omnivore-anchor-idx="36">：</strong>由 GNOME 项目组开发的一款简易、实用的扫描工具，多为主流发行版自带。</li><li data-omnivore-anchor-idx="37"><a data-omnivore-anchor-idx="38" href="https://sspai.com/link?target=https%3A%2F%2Fapps.kde.org%2Fzh-cn%2Fskanlite%2F" target="_blank"><strong data-omnivore-anchor-idx="39">Skanlite</strong></a><strong data-omnivore-anchor-idx="40">、</strong><a data-omnivore-anchor-idx="41" href="https://sspai.com/link?target=https%3A%2F%2Fapps.kde.org%2Fzh-cn%2Fskanpage%2F" target="_blank"><strong data-omnivore-anchor-idx="42">Skanpage</strong></a><strong data-omnivore-anchor-idx="43">：</strong>由 KDE 项目组开发的扫描工具。前者的界面类似于 Epson Scan 2 与 Windows 自带的扫描工具，支持预览（即「预扫描」），倾向于单页扫描；后者则为多页扫描而优化。</li><li data-omnivore-anchor-idx="44"><a data-omnivore-anchor-idx="45" href="https://sspai.com/link?target=https%3A%2F%2Fwww.naps2.com%2F" target="_blank"><strong data-omnivore-anchor-idx="46">NAPS2（Not a PDF Scanner 2）</strong></a><strong data-omnivore-anchor-idx="47">：</strong>由 CyanFish 开发的跨平台、多功能扫描工具，比 Simple Scan 功能更丰富，提供了图片裁切、OCR 等高级功能，支持导出的格式更多。</li></ul><p data-omnivore-anchor-idx="48">你可以根据自己的实际需要来选择。为便于大家快速上手，下文选用 Simple Scan 作为扫描程序。</p><h2 data-omnivore-anchor-idx="49" id="ss-hId-2" hid="ss-hId-2">准备工作：安装必要的软件包</h2><p data-omnivore-anchor-idx="339">文本</strong>、<strong data-omnivore-anchor-idx="340">图像</strong>两种扫描模式；Simple Scan 同样也支持。<sup data-omnivore-anchor-idx="341" href="" footnote-id="9" data-title="当然，很多时候 Windows 下的厂商扫描软件（如 Epson Scan 2）会提供超过两种模式，例如独立的黑白模式。">9<div data-omnivore-anchor-idx="342"><p data-omnivore-anchor-idx="343">当然，很多时候 Windows 下的厂商扫描软件（如 Epson Scan 2）会提供超过两种模式，例如独立的黑白模式。</p></div></sup>两种模式的区别在于：</p><ul data-omnivore-anchor-idx="344"><li data-omnivore-anchor-idx="345"><strong data-omnivore-anchor-idx="346">文本模式</strong>适合扫描文稿，它会对文稿进行针对性的优化，使文稿更清晰易读；</li><li data-omnivore-anchor-idx="347"><strong data-omnivore-anchor-idx="348">图像模式</strong>则会忠实还原文稿的色彩、亮度，适合扫描照片、印刷品等。</li></ul><p data-omnivore-anchor-idx="349">你可以点击左上角「扫描」按钮右侧的齿轮按钮，在弹出的菜单中切换「文本」与「图像」模式。</p><figure data-omnivore-anchor-idx="350"><img data-omnivore-anchor-idx="351" data-omnivore-original-src="https://cdnfile.sspai.com/2024/08/12/b5be95048c3c1de81830aade897430d2.png?imageView2/2/format/webp" 打印测试页的效果。左侧为文本模式，右侧为图像模式。</figcaption></figure><h3 data-omnivore-anchor-idx="353">2）设置读取文稿的模式</h3><p data-omnivore-anchor-idx="354">常用的扫描仪有三种：</p><ul data-omnivore-anchor-idx="355"><li data-omnivore-anchor-idx="356">使用文稿台的<strong data-omnivore-anchor-idx="357">平板扫描仪</strong>（一体机上的扫描仪也属于平板扫描仪<sup data-omnivore-anchor-idx="358" href="" footnote-id="10" data-title="本节不考虑顶部连续进纸的扫描模式。">10</sup>），需要你打开盖子，把文稿放在玻璃台上。一次只能扫描一张 A4 纸文稿。</li><li data-omnivore-anchor-idx="359">支持高速进纸的<strong data-omnivore-anchor-idx="360">馈纸式扫描仪</strong>（又称高速扫描仪），就像打印机一样放入文稿，一分钟可以扫描数十张文稿，还支持双面扫描<sup data-omnivore-anchor-idx="361" href="" footnote-id="11" data-omnivore-anchor-idx="364">使用摄像头的<strong data-omnivore-anchor-idx="365">高拍仪</strong>，一次只能扫描一张 A4 纸文稿。</li></ul><p data-omnivore-anchor-idx="366">由此可见，三种扫描仪各有不同的文稿读取模式。Simple Scan 允许你根据扫描仪的具体情况，来决定如何读取文稿。同样是点击左上角「扫描」按钮右侧的齿轮按钮来设置：</p><ul data-omnivore-anchor-idx="367"><li data-omnivore-anchor-idx="368"><strong data-omnivore-anchor-idx="369">单页：</strong>默认模式，一次只扫描一个页面。</li><li data-omnivore-anchor-idx="370"><strong data-omnivore-anchor-idx="371">传送来的所有页面：</strong>适用于馈纸式扫描仪的模式，可以一次连续扫描多个页面，再传送到 Simple Scan 中。若你使用馈纸式扫描仪，却将 Simple Scan 设置「单页」模式，你就要反复点击「扫描」按钮来进行多页扫描。</li><li data-omnivore-anchor-idx="372"><strong data-omnivore-anchor-idx="373">来自平板扫描仪的多个页面：</strong>扫描一个页面后，Simple Scan 会提示你是否继续扫描，你可以更换文稿后点击「继续」，添加新页面；或点击「结束」，完成扫描。这一工作模式类似于 Epson Scan 2 等扫描软件在平板扫描仪上的的「多页模式」。</li></ul><h3 data-omnivore-anchor-idx="374">3）设置扫描质量</h3><p data-omnivore-anchor-idx="375">正如官方扫描软件一样，Simple Scan 允许你在「首选项」中设置扫描质量，包括分辨率、亮度、对比度等。如下图所示：</p><figure
