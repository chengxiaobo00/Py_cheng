data-omnivore-anchor-idx="14"><p data-omnivore-anchor-idx="15">不知不觉，我日常使用 Linux 已经有第 6 个年头了。一个词概括，「<strong data-omnivore-anchor-idx="16">舒适</strong>」。</p><p data-omnivore-anchor-idx="17">Linux，也许在很多读者的印象里，是 「难用」「高门槛」 的，各种「劝退」。要想使用，最多只是退而求其次安在虚拟机里，或者是与既有的 Windows 组成双系统。要是当作电脑里唯一的系统使用，或许是一种挑战。</p><p data-omnivore-anchor-idx="18">但是，对我来说，我的日常离不开 Linux。我的两台经典款 ThinkPad 笔记本，都只安装 Arch Linux 这一款 Linux 发行版。得益于开发团队的高度优化，以及丰富的软件资源，在 Arch Linux 这样的发行版上工作、娱乐，其体验完全不亚于 Windows 与 macOS「两巨头」，我每天都能乐在其中。</p><p data-omnivore-anchor-idx="19">事实上，<strong data-omnivore-anchor-idx="20">以 Linux 作为日常使用的系统，门槛是存在的，但其实远没有想象的那么高</strong>。看清这门槛的本质，以适当的方法和技巧来「行走」，你就会发现，原来这门槛竟可以轻轻一抬脚跨过去。</p><p data-omnivore-anchor-idx="21">接下来，我会向大家分享日常使用 Linux 的经验与心得，旨在帮助大家轻松迈过门槛，「重新」爱上 Linux。</p><p data-omnivore-anchor-idx="22">我开始接触 Linux 是在高中时期。一开始，也和刚入门 Linux 的玩家们一样，与 Windows 并存，作为编程开发专用的系统。主阵地仍在 Windows。</p><p data-omnivore-anchor-idx="23">直到 2018 年。当时我大三，发现每天带着 15.6 英寸的笔记本到处跑，真是不便，于是就想淘一台轻便的笔记本。我是经典款 ThinkPad 的爱好者，始终惊艳于中学同学家 ThinkPad 屏幕下那一排独具专业范的指示灯，于是果断入手了一台 ThinkPad X200。</p><p data-omnivore-anchor-idx="24">然而在那时，ThinkPad X200 已经是近 10 年前的笔记本，配置跟不上时代了：</p><ul data-omnivore-anchor-idx="25"><li data-omnivore-anchor-idx="26"><strong data-omnivore-anchor-idx="27">处理器：</strong>Intel Core 2 Duo P8600，主频 2.4 GHz</li><li data-omnivore-anchor-idx="28"><strong data-omnivore-anchor-idx="29">内存：</strong> 4 GB DDR3</li><li data-omnivore-anchor-idx="30"><strong data-omnivore-anchor-idx="31">显卡：</strong>Intel GM45 集成显卡</li><li data-omnivore-anchor-idx="32"><strong data-omnivore-anchor-idx="33">硬盘：</strong>128 GB SSD（我自行更换）</li></ul><p data-omnivore-anchor-idx="34">这个配置，跑 Windows 7 尚且绰绰有余，但微软已经不再支持；跑 Windows 10 太勉强，这玩意给 4GB 内存未必够用。我甚至还试着运行过 macOS，可以引导，但是缺少驱动，根本无法好好使用。</p><p data-omnivore-anchor-idx="35">就在这时，我想到前不久看见社团同学在用一款名为 Deepin 的 Linux 发行版。那么，何不试试？于是，果断行动，下载安装 Deepin，再安装 WPS 等常用软件，于是正式开启了我的单系统 Linux 日用之旅。这台 X200，成为了我学习的搭档，伴着我走过了本科的最后一年。我全程用它来创作毕业论文，课余时间还写程序、玩 Docker、看视频…… 不亦乐乎。</p><p data-omnivore-anchor-idx="36">不觉间，Linux 已经成为了我生活的一部分，Deepin 让这台十余年历史的老笔记本焕发新光彩，宝刀不老，持续再战。当然，我也没有止步于此，毕业后依次尝试了 Linux Mint、Manjaro 与 Arch Linux，最终选择 Arch Linux 作为我的归宿。</p><p data-omnivore-anchor-idx="37">Arch 的安装过程一时间难于上手，但这没有难倒热爱技术的我，而我也很享受掌控安装全过程的感觉。配合 Arch，X200 的表现更上一层楼，丝滑流畅，继续伴我同行。</p><p data-omnivore-anchor-idx="38">简单讲完了我日常使用 Linux 的体验，我想大家也许对 Linux 有了那么一点点全新的认识。不过，作为操作系统「三巨头」（Windows、macOS、Linux）中，分量没那么高、技术要求却更高一些的成员，可能很多朋友对日常使用 Linux 有些担忧。下面，且让我来梳理一下。</p><h3 data-omnivore-anchor-idx="39">使用门槛高？</h3><p data-omnivore-anchor-idx="40">说到 Linux，也许朋友们会问，<strong data-omnivore-anchor-idx="41">是不是需要很强的计算机应用知识才能掌握</strong>，是不是要像当年学 DOS 那样去记一堆命令，它是不是比 Windows 还难用，等等。</p><p data-omnivore-anchor-idx="42">其实不然。<strong data-omnivore-anchor-idx="43">现在的 Linux 发行版，有相当一部分就是面向个人用户的。它们自带桌面环境（Desktop Environment），通俗来说，就是安装好后直接进入桌面</strong>，提供一系列图形界面应用软件，文件管理、多媒体、网页浏览器、系统设置等等，应有尽有，就和你平时使用 Windows 和 macOS 一样。</p><figure data-omnivore-anchor-idx="44"><img data-omnivore-anchor-idx="45" data-omnivore-anchor-idx="49">新手入门的话，通常不需要，也不必要接触这些发行版，因此大可不必担心。</strong></p><p data-omnivore-anchor-idx="50">如果你只是使用图形界面的话，文件管理器等基本软件其实不需要教程，它们本身的界面就足够简洁易懂，这足以大大降低使用门槛。</p><p data-omnivore-anchor-idx="51">而如果你想要进一步深入学习，那么作为有开发者社群支持的操作系统，<strong data-omnivore-anchor-idx="52">Linux 及其发行版有完备的技术支持，也有广大的技术爱好者们愿意用爱发电</strong>，贡献各类文档和教程，例如：</p><ul target="_blank">菜鸟教程 </a>，就提供了一套 <a data-omnivore-anchor-idx="56" href="https://sspai.com/link?target=https%3A%2F%2Fwww.runoob.com%2Flinux%2Flinux-intro.html" target="_blank">清晰易懂的 Linux 入门指南</a>。虽然是面向服务器运维的，但也适合新手了解 Linux 命令的使用。</li><li data-omnivore-anchor-idx="57">著名的 Linux 应用大神鸟哥，也推出了 <a data-omnivore-anchor-idx="58" href="https://sspai.com/link?target=https%3A%2F%2Fwizardforcel.gitbooks.io%2Fvbird-linux-basic-4e%2Fcontent%2Findex.html" target="_blank">《鸟哥的 Linux 私房菜：基础学习篇》</a>，帮助你由浅入深掌握 Linux。</li><li data-omnivore-anchor-idx="59">不会使用 Linux 命令或软件？只需在必应等搜索引擎一搜，你往往就能找到不少技术达人写的教程。</li></ul><p data-omnivore-anchor-idx="60">另外，我个人认为，日常使用的 Windows，本身就配备了大量高技术、高门槛的功能特性，其难度未必比 Linux 低。例如，PowerShell、DISM（管理操作系统映像和组件的工具），以及 <code data-omnivore-anchor-idx="61" class="hljs language-gcode">syste<span data-omnivore-anchor-idx="62" class="hljs-name">m32</span></code> 目录和注册表的你，或许也曾震撼于迷宫般复杂、鱼群般数量庞大的文件组织结构。</p><p data-omnivore-anchor-idx="65">好在，Windows 设计得当，我们大多数时候不会涉及到如此高端的操作。同理，像 Deepin、Manjaro 这样日常向、新手向的发行版也是如此，得益于设计良好的桌面环境，新手动动鼠标即可完成日常工作。</p><h3 data-omnivore-anchor-idx="66">界面不好用？</h3><p data-omnivore-anchor-idx="67">在刷少数派与 Linux 相关的文章时，有些网友不主张日常使用 Linux，他们认为「装虚拟机用用就行」「要用 Linux 就不要装桌面，老老实实在终端模式下输命令」。</p><p data-omnivore-anchor-idx="68"><strong data-omnivore-anchor-idx="69">其实，放在数十年前，甚至 2010 年代初，这样的观点不无道理，就是在直指 Linux 的痛点之一：缺乏好用的桌面环境（desktop environment, DE）</strong>。早期 Linux 桌面环境，功能不完善，操作逻辑与大家熟悉的 Windows 相去甚远；UI 风格堪称「活化石」，设计风格陈旧，被同时期的 Windows Vista 和 Windows 7 甩出几条街。</p><p data-omnivore-anchor-idx="70">例如，下面这幅图是 <a data-omnivore-anchor-idx="71" Windows，界面采用清爽的扁平化设计，易上手，用着更舒服：</p><figure data-omnivore-anchor-idx="77"><img data-omnivore-anchor-idx="78" Linux 发行版摆脱了 「界面难用」 的局限性，其易用性和便捷性已经不输给 Windows 和 macOS。现在，就只差你的尝试了。</p><h3 data-omnivore-anchor-idx="93">操作不习惯？</h3><p data-omnivore-anchor-idx="94">刚入门 Linux 发行版的朋友，<strong data-omnivore-anchor-idx="95">最担心的问题或许也是能否习惯 Linux 的操作逻辑</strong>。历年的计算机普及教程以 Windows 为主，很多朋友接触的计算机操作系统就以 Windows 居多。而部分 Linux 桌面环境在默认配置下，界面布局、操作习惯等与 Windows 大相径庭，用户不得不面临操作习惯的适应问题。</p><p data-omnivore-anchor-idx="96">幸运的是，各路开发团队已经取得了突破性成果，已经能让习惯 Windows 的用户快速上手 Linux 发行版：</p><ul data-omnivore-anchor-idx="97"><li data-omnivore-anchor-idx="98">相当一些发行版及其桌面环境，在设计上尽可能与 Windows 一致。例如上文提到的发行版 <strong data-omnivore-anchor-idx="99">Zorin OS</strong>、<strong data-omnivore-anchor-idx="100">Linux Mint</strong>、搭载 UKUI 的<strong data-omnivore-anchor-idx="101">银河麒麟</strong>与<strong data-omnivore-anchor-idx="102">优麒麟</strong>，就是还原了 Windows 的操作体验，大大降低学习成本。</li><li data-omnivore-anchor-idx="103">另一些发行版，会对已有的桌面环境做针对性的优化，使其更易用。例如 <strong data-omnivore-anchor-idx="104">Manjaro</strong> 就对 Xfce 做了深度定制，将任务栏放在底部、安装增强的启动器插件（相当于「开始菜单」），使其对新手友好。</li></ul><p data-omnivore-anchor-idx="105">因此，<strong data-omnivore-anchor-idx="106"> 我建议优先选择这些对新手友好的发行版</strong>。</p><h3 data-omnivore-anchor-idx="107">软件资源少？</h3><p data-omnivore-anchor-idx="108">放在十几年前，缺乏软件资源的确是桌面 Linux 发行版的「硬伤」，足以劝退想尝试 Linux 的用户。大厂很少推出适用于 Linux 平台的软件，即使能推出也是滞后于另两大平台，无法保证体验的一致性。而已有的 Linux 软件阵容，虽然不乏优秀的产品，但与专业竞品未必有可比性。</p><p data-omnivore-anchor-idx="109">如今则大不一样了。无论是大厂还是开源软件开发者，现在都越来越重视 Linux 平台，Linux 这块昔日的应用软件「北大荒」，已经蝶变成为「北大仓」。</p><p data-omnivore-anchor-idx="110">且看下面这些可喜的例子：</p><ul data-omnivore-anchor-idx="111"><li data-omnivore-anchor-idx="112"><strong data-omnivore-anchor-idx="113">办公软件：</strong>WPS for Linux 的诞生，彻底改写了长期以来 Linux 平台办公软件匮乏的历史，畅快办公不再是梦。</li><li data-omnivore-anchor-idx="114"><strong data-omnivore-anchor-idx="115">开发工具：</strong>微软为 Visual Studio Code 推出了 Linux 版本，JetBrains 旗下的王牌 IDE 系列也能原生在 Linux 下运行。</li><li data-omnivore-anchor-idx="116"><strong data-omnivore-anchor-idx="117">网络浏览器：</strong>Google Chrome 和 Mozilla Firefox 早已推出 Linux 版本，功能体验与 Windows 版一致。</li><li data-omnivore-anchor-idx="118"><strong data-omnivore-anchor-idx="119">影音播放：</strong>你可以使用 VLC、SMPlayer 来观赏视频，用 Audacious 来听音乐。</li><li data-omnivore-anchor-idx="120"><strong data-omnivore-anchor-idx="121">游戏：</strong>著名游戏平台 Steam 已经推出了官方 Linux 版本，畅玩游戏不是梦。</li></ul><p data-omnivore-anchor-idx="122"><strong data-omnivore-anchor-idx="123">发行版的开发团队，也在努力完善 Linux 的软件生态。</strong> 在软件适配方面最积极的是 Deepin，在它的应用商店里，你可以下载到不少常用应用，从办公到影音娱乐应有尽有，甚至还有我们熟悉的 QQ、微信、WPS。</p><figure data-omnivore-anchor-idx="124"><img data-omnivore-anchor-idx="125" 日常工作体验，如今就在你眼前，就在你身边。</p><h2 data-omnivore-anchor-idx="136" id="ss-hId-3" hid="ss-hId-3">日常使用 Linux 的好处</h2><p data-omnivore-anchor-idx="137">就我自己的体验来说，我爱 Linux，不仅仅是因为它是我日常生活的组成部分，更是因为它给带来的是实打实的好处。</p><h3 data-omnivore-anchor-idx="138">老机器焕发新生</h3><p data-omnivore-anchor-idx="139">Linux 发行版普遍对硬件要求不高，即使是十几年前的电脑也能畅快驾驭，流畅运行。</p><p data-omnivore-anchor-idx="140">我手上的「古董」ThinkPad 有两台：X200、R400。它们都只有 4GB 内存，处理器主频偏低（分别为 2.4 GHz 与 2.5 GHz），运行 Windows 10 与 Windows 11 已经力不从心。</p><p data-omnivore-anchor-idx="141">但是，在安装 Arch Linux 之后，这两台老机器焕发第二春，配合 SATA SSD 满血复活，软件可以实现「秒开」，运行体验丝滑流畅。同时，得益于 Arch 的滚动更新机制，三台笔记本随时都可以用上最新版的 LTS 内核及应用软件，安全和性能都有保障。</p><p data-omnivore-anchor-idx="142">因此，我只需以极其低廉的价格购买二手的老笔记本，搭配 Linux 发行版，即可再给自己添加几员「得力干将」。</p><h3 data-omnivore-anchor-idx="143"><strong data-omnivore-anchor-idx="144">促进环保与资源利用</strong></h3><p data-omnivore-anchor-idx="145">接下来，让我们再放眼世界。</p><p data-omnivore-anchor-idx="146">每年都有海量的电脑因 「配置老旧」 被淘汰。而 Windows 11 引进的所谓升级标准——酷睿第 8 代起步，加上 TPM 支持，更是让诸多配置尚可的电脑无法享受最新的 Windows 系统服务，也被迫「淘汰」。</p><p data-omnivore-anchor-idx="147">这未尝不是一种资源浪费。要知道，这些电脑运行 Linux 发行版仍绰绰有余——通常个人用的 Linux 发行版只需 64 位处理器，4GB 起步的内存，以及 SATA SSD，不需要更多。如果能让这些电脑运行 Linux 发行版，将无形中减少浪费，为地球 「减负」 增一份力量。</p><p data-omnivore-anchor-idx="148">Zorin OS data-omnivore-anchor-idx="154">Linux 略高的门槛，意味着使用者可以从玩转 Linux 的过程中，学到计算机应用的真功夫。因为在日常应用中涉及的知识点需要你自己探究，遇到的问题需要你自己解决，而每一次解决的经验都是你精通计算机之路上的助力。</p><p data-omnivore-anchor-idx="155">解决问题的过程并不是难于登天的。得益于 Linux 发行版与软件的社区支持，你可以查阅发行版与软件的文档，也可以在必应等搜索引擎检索玩家们的博客。举两个例子：</p><ul data-omnivore-anchor-idx="156"><li data-omnivore-anchor-idx="157">如果你用 Manjaro，不会用 Pacman 命令，就可以在必应搜索 「pacman 入门」 或「pacman 用法」。</li><li data-omnivore-anchor-idx="158">如果程序运行时出现了什么错误，你可以记下错误信息，然后同样用搜索引擎搜索。</li></ul><p data-omnivore-anchor-idx="159">对于新手来说，很多基础问题都是可以用上面的思路来找到解决方案的，不必太过担心。你在寻找解决方案的过程中，跟着实践，不知不觉就会逐步积累经验。</p><p data-omnivore-anchor-idx="160">我就是这么练出来的，从最早试着在 Android 智能 MP4 上捣鼓 Linux 命令，到现在日常使用 Linux，丰富的经验就是在不停 「提问」 与实践中，潜移默化积累的。相信你也可以。（就我的体会来说，这样探究和解决问题的过程，放在 Windows 与 macOS 里也是一样的。）</p><h2 data-omnivore-anchor-idx="161" id="ss-hId-4" hid="ss-hId-4">写在最后</h2><p data-omnivore-anchor-idx="162">以上就是我日常使用 Linux 的一些经验体会，相信这篇文章能够更新你对 Linux 及其发行版的看法。</p><p data-omnivore-anchor-idx="163">Linux
