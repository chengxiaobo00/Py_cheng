data-omnivore-anchor-idx="152">关键词：素材管理、设计工具</li></ul><p data-omnivore-anchor-idx="153"><a data-omnivore-anchor-idx="154" data-mention="@化学心情下2" user-id="bs2od75b34tch2730oa0" href="https://sspai.com/u/liuxiaofengone">@化学心情下2</a>：老牌素材管理工具 Eagle 近期迎来 4.0 大版本升级，通过更多功能将帮助你更好地完成设计工作。</p><p data-omnivore-anchor-idx="155">Eagle 4.0 中最为重要以及核心的功能，应该就是全新引入的插件系统——没错，通过各种第三方插件可以更好地适配不同的设计场景，除了开发者可以根据 API 来进行插件开发之外，用户可以通过新上线的插件中心来下载和使用插件。目前上线的插件包括了格式转换压缩、下载管理以及支持格式扩展等等，已经有不少官方插件可供我们选择使用了。</p><figure data-omnivore-anchor-idx="156"><img Eagle 4.0 中，你会发现整体界面使用了透明毛玻璃的效果，更符合现代的软件界面风格。应用内的辅助插图也进了更新，看上去质感和整个界面风格保持统一，也更符合设计内工具这一产品定位。</p><figure data-omnivore-anchor-idx="159"><img data-omnivore-anchor-idx="160" data-omnivore-anchor-idx="161">据开发者介绍，Eagle 4.0 在性能上也进行了深度优化，比如软件开启速度比以往提升 20%、HEIC 图片解码、高分辨率图片解码等都提升了至少 200%，同时对于巨型资源库加载也减少了 20% 到 30% 的内存使用。</p><p data-omnivore-anchor-idx="162">对于一款设计素材的收集管理工具，格式的支持其实最为重要，在 Eagle 4.0 中新增了多种文件格式，视频格式中新增 H.265、gifv、3gp 、afx、eva、vap、图片格式中新增 eps 、avif、jpegxl、jfif、jpe、insp，3D 模型里面新增了 3ds、3mf、dae、ifc、ply、stl、glb、另外还加入了对网页、电子书以及动画格式的支持。</p><p data-omnivore-anchor-idx="163">扫描重复文件一直都是 Eagle 最为实用的功能之一，而在 4.0 新版中这个功能被重新规划成「扫描相同的文件」和「扫描相似的图片」，其中「扫描相同的文件」指的是从格式还是视觉上完全都一致的文件，也就是完全的去重；而扫描相似的图片则是视觉上相似的文件，这个则需要通过算法来做判断，而最终会将结果一目了然地展示出来，方便进行选择和合并。</p><figure data-omnivore-anchor-idx="164"><img data-omnivore-anchor-idx="167">此外，在本次更新中还着重对右键菜单进行了优化，引入的搜索功能可以让用户在打开右键菜单后直接输入关键词，快速找到所需功能，可以非常方便找到想要的功能和素材，同时进一步的简化操作。</p><p data-omnivore-anchor-idx="168">除了上述的这一些功能之外，Eagle 4.0
