iPad 绘画这件事变得门槛更低、更加方便。</p><p data-omnivore-anchor-idx="4">但如果是十年前呢？在那个没有 Apple Pencil、绘画 app 的数量和功能都相对匮乏的时代，如果有人说 iPad 是一款专业的绘画工具，想必很难令人信服。不过，有这么一位创作者，他被称为「最著名的英国在世画家」，早在十多年前就用手指在 iPad 上创作出了不少享誉国际画坛的作品，他就是大卫 · 霍克尼 (David Hockney)。</p><figure data-omnivore-anchor-idx="5"><img data-omnivore-anchor-idx="6" iPad 在创意创作领域的巨大演进与创作能力。</p><h2 data-omnivore-anchor-idx="9" id="ss-hId-1" hid="ss-hId-1">让人人都能创作</h2><p data-omnivore-anchor-idx="10">当然，即使是在如今，我们也不可能用手指、甚至是直接用 Apple Pencil 在 iPad 上画出如大卫 · 霍克尼当年创作的诸多优秀画作。但毫无疑问，随着 iPad 在过去十多年间的不断迭代，并且有了 App Store 应用生态的日益繁荣，随时随地拿出 iPad 画点什么，对于每个人而言都不再是遥不可及的一件事，而这，也一直是 Procreate 背后的开发团队 Savage Interactive 为之奋斗的目标。</p><figure data-omnivore-anchor-idx="11"><img data-omnivore-anchor-idx="12" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/31/5d7d5bb0304e6be6837d13ac152a77c3.jpg?imageView2/2/format/webp" iPad 的历史画卷，见证着这款产品走过的每一个脚步。如今的 Procreate 是两届 Apple 设计大奖的最终得主，充分利用着 iPad 和 Apple Pencil 硬件平台上的各种优势。有了 Apple Pencil 内置的强大传感器，以及倾斜感应、压力感应等一系列实用功能，Procreate 得以在 iPad 上提供超过 200 款笔触自然、效果出众的画笔工具，同时利用 iPad 尤其是 iPad Pro 上的顶级屏幕，呈现出更加准确的色彩，更全面地传递创作意图。</p><p data-omnivore-anchor-idx="14">创始人 James Cuda 也曾在今年 <a data-omnivore-anchor-idx="15" href="https://sspai.com/post/89816">WWDC24 的现场</a>向我表示，很高兴能拥有 iPad 和 Apple Pencil 这样的设备，让开发团队能够帮助用户在数字平台上找到更接近真实纸面的创作体验。</p><p data-omnivore-anchor-idx="16">而此次在艺仓美术馆，Procreate 团队的成员们也向我们再次展示了旗下最新的作品：Procreate Dreams。夸张一点说，即使你不具备任何动画制作的知识和能力，也可以很快上手这款 app，做出一个效果还不错的动画视频，不论是创建物体动效的拖动操作方式，还是用 Apple Pencil 手势快速切换图层，Procreate Dreams 的使用逻辑都与我们已经非常熟悉的交互操作相当符合。</p><figure data-omnivore-anchor-idx="17"><img data-omnivore-anchor-idx="18" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/31/44a8a476dad60fb2f31dc77cc7c07fc0.jpg?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,shXCxLqQdDphLXr_Lu4F1iLN2qH3MYWYuLaoglKsrmwM/https://cdnfile.sspai.com/2024/07/31/44a8a476dad60fb2f31dc77cc7c07fc0.jpg?imageView2/2/format/webp" data-original="https://cdnfile.sspai.com/2024/07/31/44a8a476dad60fb2f31dc77cc7c07fc0.jpg?imageView2/2/format/webp" data-index="2"></figure><p data-omnivore-anchor-idx="19">而对于专业功能，Procreate Dreams 的操作方式也很简单。比如开发团队现场向我们演示了如何在动画场景中添加更加自然的动态前后景深效果，只需要选择效果、选中对象，剩下的交给应用去完成就好了。</p><p data-omnivore-anchor-idx="20">开发团队告诉我们，能如此简单地实现这些高级功能，也要得益于 iPad Pro 芯片的强大算力。有了 M4 芯片的加持，Procreate Dreams 才能做到如此逼真而又实时的即时渲染能力。</p><h2 data-omnivore-anchor-idx="21" id="ss-hId-2" hid="ss-hId-2">让专业创作更快</h2><p data-omnivore-anchor-idx="22">对于 iPad Pro 上 M4 芯片的强大算力，SketchUp 和 Octane X 的团队成员们也深以为然。</p><p 就能借助云端 AI 能力完成一份设计文件的 3D 实景渲染模型。</p><figure data-omnivore-anchor-idx="24"><img data-omnivore-anchor-idx="25" 的运用变得更加广泛、更加高效。设计师可以利用这样灵巧的设备随时随地查看工作文件、预览渲染效果，也可以带着 iPad 直接向用户演示实景渲染图，方便后续的沟通与讨论。</p><p data-omnivore-anchor-idx="27">而在现场，专业级三维渲染工具 Octane X 的团队成员们也向我们宣布了，Octane X 将支持中文语言的好消息。作为桌面平台最老牌的专业级渲染工具之一，Octane X 在 iPad 上不仅提供了与 macOS 一致的全部功能，也对这一设备做了针对性的交互适配。比如界面上的设计调整，以及支持多点触控操作和 Apple Pencil 等等。</p><p data-omnivore-anchor-idx="28">对于有更高需求的用户，Octane X for iPad 也支持外接键鼠、显示器等设备实现更高效的操作方式，这些特性都让 iPad 上的 Octane X 使用体验进一步接近桌面端，但又更加灵活与方便。</p><figure data-omnivore-anchor-idx="29"><img data-omnivore-anchor-idx="30" Octane X 是如何在数秒之间就完成了许多复杂场景的实时本地渲染工作。M4 芯片的 GPU 能够帮助 Octane X 实现影院级的光线追踪能力，团队成员告诉我们。</p><h2 data-omnivore-anchor-idx="32" id="ss-hId-3" hid="ss-hId-3">表达比工具更重要</h2><p 非常喜欢的变化。</p><p data-omnivore-anchor-idx="43">此次，Percy Lau 也是从没有绘画基础开始，用 iPad Pro 加上 Apple Pencil Pro，对游戏《崩坏：星穹铁道》中的国风角色阮·梅进行了二次绘画创作。Percy Lau 坦言，本次创作对于自己而言算是一次「走出舒适区」的尝试，从不会画画到自学 Octane X、Shapr 3D 这些专业级的建模和渲染工具，并用 Procreate 将这些创意真正画出来，Percy Lau 也仅用了几天的时间。</p><p data-omnivore-anchor-idx="44">&gt; <a data-omnivore-anchor-idx="45" href="https://m.weibo.cn/status/5060356290118356"
