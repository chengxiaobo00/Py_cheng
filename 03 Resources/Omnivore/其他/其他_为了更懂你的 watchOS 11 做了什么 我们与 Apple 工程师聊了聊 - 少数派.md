睡觉即可。</p><p data-omnivore-anchor-idx="23">不仅有新的分析功能，从体能训练的自定义能力到更加灵活和直观的图表呈现方式，也让 watchOS 11 在健康领域更进一步，让原来机械性的数据传递出更多有价值的信息。比如游泳现在也可以成为自定义体能训练了，而对于所有定制化的体能训练，都可以针对每个统计阶段单独命名，方便查看以及后期回顾。而在 iPhone 的健身 app 里，摘要页视图的数据卡片可以让用户自由调整和排布，你可以只把自己最关注的信息呈现在此，打造一个专属于你的健身 app。</p><figure data-omnivore-anchor-idx="24"><img data-omnivore-anchor-idx="25" 公开测试版本也已经推出，也希望已经体验到新版系统的用户，能够通过 watchOS 11 帮助自己迈出健康步调，维持更加良好的身体状态。</p><h2 data-omnivore-anchor-idx="27" id="ss-hId-2" hid="ss-hId-2">功能愈发开放，提供更多可能</h2><p data-omnivore-anchor-idx="28">除了健康方面的功能，watchOS 11 也向开发者们开放和升级了许多系统级能力。</p><p data-omnivore-anchor-idx="29">最让人关注的特性之一，当属双指互点两下 (Double Tap) API 的开放了。我们得知，双指互点两下也不只是开放了 API 那么简单，在 watchOS 11 上，这项功能已经成为了全局性的系统能力，你不仅可以向之前一样用双指互点手势接电话、暂停计时器等等，也可以在所有垂直列表或视图中，通过这一手势来向下滚动浏览。</p><figure data-omnivore-anchor-idx="30"><img data-omnivore-anchor-idx="31" data-original="https://cdnfile.sspai.com/2024/07/18/93d1a5f51d85eb6a5bd69cecdf965554.gif" data-index="5"></figure><p data-omnivore-anchor-idx="32">更好的消息是，开发者无需进行任何适配，也可以让双指互点操作应用在自己的 app 中，让用户向下浏览与交互。</p><p data-omnivore-anchor-idx="33">当然，得益于双指互点两下 API 的释出，开发者也可以针对性地将自己 watchOS 应用中的某一个按钮或者控件指定为主要操作 (primary action)，让用户可以在使用这些 app 享受到更便捷、更高效的体验。</p><p data-omnivore-anchor-idx="34">Lori 也特地向我们展示了她为自己的先生设计的一款 app，只需要双指一点，就能立刻记录到当下对于像是苹果或橘子的摄取量，以此来督促自己的先生更多地摄入蔬果等营养物质。</p><p data-omnivore-anchor-idx="35">双指互点两下 API 为开发者提供了更多机会，让他们可以在 Apple Watch 上重新设想自己 app 设计的方式。双指互点两下 API 的开放，能够为开发者提供更多创意灵感，也很期待能够尽快看到开发者们运用这项能力在自己的 app 中做出怎样的功能。</p><p data-omnivore-anchor-idx="36">你可能没有注意到，除了双指互点两下 API，watchOS 11 还向开发者们开放了一个全新的 API：State of Mind API。记录心理状态是去年 watchOS 10 为正念 app 推出的全新功能，可以帮助用户记录当下时刻的情绪或者每天的心情，并且培养用户记录记录心理健康的习惯以及调节能力。</p><figure data-omnivore-anchor-idx="37"><img data-omnivore-anchor-idx="38" 并向开发者们提供，我们也感到非常好奇，希望了解 Apple 希望开发者们如何应用这一能力。</p><p data-omnivore-anchor-idx="40">我们了解到，State of Mind API 的开放，并不只是为了让开发者给用户提供更多记录自己情绪的场所，当然这肯定也是其中用法。Eric 向我们举了一个实际的例子，比如当演讲者结束了自己的 Keynote 讲演之后，如果有一个 app 能够让观众记录自己会后的相应情绪和心理状态来向演讲者传递情感表达，演讲者就能通过这样的方式更有效地获得观众反馈，并在后续做好会议复盘甚至是下一次讲演的调整。</p><figure data-omnivore-anchor-idx="41"><img data-omnivore-anchor-idx="42" data-original="https://cdnfile.sspai.com/2024/07/18/e8e3a45cba0a5face4c44348323e1559.png?imageView2/2/format/webp" data-index="7"></figure><p data-omnivore-anchor-idx="43">当然，以上只是一种场景的示例。与双指互点两下 API 一样，State of Mind API 的出现能够为开发者带来更多灵感和可能，也很期待看到开发者能够如何用好这个 API，为用户带来更多实用且有意思的 app。</p><h2 data-omnivore-anchor-idx="44" id="ss-hId-3" hid="ss-hId-3">提醒更多智能，场景更加灵活</h2><p data-omnivore-anchor-idx="45">在去年 watchOS 10 中推出经过全新设计的智能叠放之后，今年这一功能也有了比较重要的升级：watchOS 11 中的智能叠放支持同步并显示 iOS 18 上的实时活动了。</p><p data-omnivore-anchor-idx="46">与双指互点两下 API 一样，这项能力几乎不需要开发者做适配工作，只要升级到 watchOS 11，目前已经适配这一特性的 iOS 应用，会将正在进行的实时活动自动同步到 watchOS 11 的智能叠放中；当然，也不需要应用提供 watchOS 版本。</p><figure data-omnivore-anchor-idx="47"><img data-omnivore-anchor-idx="48" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/18/ba9a035621ca2840cb0ce4ef49fcd8eb.PNG?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sPJ0Y3mT8sNPGA9K7wExLeUIfufpplBoIas-jSZq-W1w/https://cdnfile.sspai.com/2024/07/18/ba9a035621ca2840cb0ce4ef49fcd8eb.PNG?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" watchOS 出现实时活动时，自动在表盘上显示智能叠放界面，真正做到解放双手、即时信息一瞥就有。</p><p data-omnivore-anchor-idx="50">在 watchOS 11 出现实时活动这一新的小组件形式之后，智能叠放对于界面中可以存在的小组件数量限制也得以突破。我们也感到好奇，对于这一界面中可能出现的更多的小组件信息，Apple 方面是否会担心造成界面信息略为繁杂，影响用户的使用效率。</p><figure data-omnivore-anchor-idx="51"><img data-omnivore-anchor-idx="52" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/18/a3f9138337d76b6cfd8ccd2bd892caee.PNG?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sbL1JNhAudLlfMxiVD3_dWdVr0sj-yYj5kaF0HWTJ1Jc/https://cdnfile.sspai.com/2024/07/18/a3f9138337d76b6cfd8ccd2bd892caee.PNG?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" 中智能叠放和实时活动的设计原则，都是以「相关性」和「切实性」为出发点进行考量。watchOS 11 会运用机器学习以及相关性引擎的能力，将当下时刻与你最相关的正在进行的活动放在首位进行展示，确保你不会错过最重要的信息。因此，有了实时活动的加入，只会让智能叠放功能更加智能、更加实用，完全不会担心出现信息过载的问题。</p><p data-omnivore-anchor-idx="54">我也进一步询问并得到证实，不论何种情形或时候，实时活动的展示优先级都会高于用户固定以及 watchOS 系统建议的小组件，并在智能叠放界面中显示在最上方。Eric 认为，watchOS 11 实时活动的这一特性让用户的使用场景更为方便，比如当处在手机放进口袋或包里的移动场景时，用户不需要掏出手机就能直接通过手腕获得实时活动的进度信息，这让 Apple Watch 的使用方式变得更为灵活了。</p><p data-omnivore-anchor-idx="55">此外，虽然实时活动不需要开发者做适配工作，但即使开发者希望做一些针对性的调整适配，让实时活动的设计更符合尺寸更小了不少的表盘上的样式，以达到更加美观和易用的目的，也只需要几行代码就可以实现这一需求。</p><p data-omnivore-anchor-idx="56">在升级到 watchOS 11 的测试版本并使用了近一个月的时间，我确实感受到有了实时活动的 watchOS 11 变得更加直观和好用了。不论是高铁的候车信息、还是航班的值机状态，看一眼就知的体验相当省心，尤其是在手上拎着包袋和行李的时候。</p><h2 data-omnivore-anchor-idx="57" id="ss-hId-4" hid="ss-hId-4">结语</h2><p data-omnivore-anchor-idx="58">在与 Eric 和 Lori 交流的过程中，他们反复提到的 watchOS 11 对于开发者而言的「机会」与「可能性」令我印象深刻。在提到 watchOS 11 的种种新特性时，他们也毫不吝惜地表达着自己的兴奋与期待，希望 watchOS 11 能够进一步帮助用户保持健康生活。</p><p data-omnivore-anchor-idx="59">有了 watchOS 11 珠玉在前，我们也很期待，即将到来的新款 Apple Watch，会带给我们什么惊喜。</p></div></DIV></DIV>
