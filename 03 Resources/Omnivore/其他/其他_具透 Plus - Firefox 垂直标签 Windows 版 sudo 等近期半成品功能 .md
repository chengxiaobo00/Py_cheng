<DIV id="readability-content"><DIV data-omnivore-anchor-idx="1" class="page" id="readability-page-1"><div data-omnivore-anchor-idx="2" data-v-1dcc4796="" data-v-7d731348=""><div data-omnivore-anchor-idx="3" data-v-7d731348=""><!----> <p data-omnivore-anchor-idx="4" data-v-7d731348="">
        Firefox 也有垂直标签栏了，但还是个半成品；微软给 Windows 仿了一个 sudo，但仅限于 sudo
      </p> <hr data-omnivore-anchor-idx="5" data-v-7d731348="">  <article data-omnivore-anchor-idx="6" data-v-7d731348=""><h2 data-omnivore-anchor-idx="7">Firefox 也有垂直标签栏了，但还是接着用插件吧</h2>
<p data-omnivore-anchor-idx="8"><a data-omnivore-anchor-idx="9" data-mention="@PlatyHsu" user-id="bs2p0qtb34tch278vgn0" href="https://sspai.com/u/platyhsu">@PlatyHsu</a>：近两年，垂直标签栏通过 Edge、Arc 等浏览器在更大众的群体中建立了认知。但从历史看，这一设计还是在 Firefox 用户中有最深厚的基础。尽管 Firefox 此前从未官方支持过垂直标签栏，但得益于很早就原生支持侧边栏，并开放给第三方扩展使用（Chrome 和 Edge 直到晚近版本才支持侧边栏及侧边栏扩展），Firefox 生态中有不少优秀的垂直标签栏扩展，以 <a data-omnivore-anchor-idx="10" href="https://sspai.com/link?target=https%3A%2F%2Faddons.mozilla.org%2Fen-US%2Ffirefox%2Faddon%2Ftree-style-tab%2F" target="_blank">Tree Style Tab</a> 为代表。这也成为很多用户留恋 Firefox 的关键原因。</p>
<p data-omnivore-anchor-idx="11">因此，当 Firefox 在 8 月发布<a data-omnivore-anchor-idx="12" href="https://sspai.com/link?target=https%3A%2F%2Fblog.nightly.mozilla.org%2F2024%2F08%2F07%2Ffirefox-sidebar-and-vertical-tabs-try-them-out-in-nightly-firefox-labs-131%2F" target="_blank">博客文章</a>，宣布在尚处于 Nightly 频道的 Firefox 131 中开放测试垂直标签栏功能，引起了不少兴奋也就是可以理解的了。然而，经过两个月的等待，当 Firefox 131 在 10 月成为正式版时，垂直标签栏并未如期亮相，甚至都没有被列入设置中的「实验室」板块。</p>
<p data-omnivore-anchor-idx="13">不过，愿意尝鲜的用户仍然可以通过 <code data-omnivore-anchor-idx="14" class="hljs language-applescript language-arduino"><span data-omnivore-anchor-idx="15" class="hljs-keyword">about</span>:config</code> 配置页面打开这个隐藏的功能。方法是，在地址栏访问 <code data-omnivore-anchor-idx="16" class="hljs language-applescript language-arduino"><span data-omnivore-anchor-idx="17" class="hljs-keyword">about</span>:config</code> 后，通过搜索框找到 <code data-omnivore-anchor-idx="18" class="hljs language-css"><span data-omnivore-anchor-idx="19" class="hljs-selector-tag">sidebar</span><span data-omnivore-anchor-idx="20" class="hljs-selector-class">.revamp</span></code> 和 <code data-omnivore-anchor-idx="21" class="hljs language-css"><span data-omnivore-anchor-idx="22" class="hljs-selector-tag">sidebar</span><span data-omnivore-anchor-idx="23" class="hljs-selector-class">.verticalTabs</span></code> 两个设置项，分别通过双击将其值翻转为 <code data-omnivore-anchor-idx="24" class="hljs language-yaml language-actionscript"><span data-omnivore-anchor-idx="25" class="hljs-literal">true</span></code>，然后重启浏览器即可。</p>
<p data-omnivore-anchor-idx="26">从实际效果来看，目前版本也确实很简陋，唯一可以调节的选项就是折叠和展开两种布局（通过工具栏的侧边栏按钮）。在标签页操作上，也只支持最基础的拖动排序，不像 Edge 那样支持分组，Arc 那样的多层级管理就更不用说了。</p>
<figure data-omnivore-anchor-idx="27"><img data-omnivore-anchor-idx="28" data-omnivore-original-src="https://cdnfile.sspai.com/2024/10/17/7d97229a185d587ceaf5e19e29290a36.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,s8rmIKdySqmdGehYfx9IpE3aOvlSzvZbKi7jD1-AS2uw/https://cdnfile.sspai.com/2024/10/17/7d97229a185d587ceaf5e19e29290a36.png?imageView2/2/format/webp" data-original="https://cdnfile.sspai.com/2024/10/17/7d97229a185d587ceaf5e19e29290a36.png?imageView2/2/format/webp" data-index="0"></figure>
<p data-omnivore-anchor-idx="29">眼尖的朋友应该会注意到侧边栏的样式也发生了变化，这个样式实际上是可以通过上面提到的 <code data-omnivore-anchor-idx="30" class="hljs language-css"><span data-omnivore-anchor-idx="31" class="hljs-selector-tag">sidebar</span><span data-omnivore-anchor-idx="32" class="hljs-selector-class">.revamp</span></code> 开关单独开启的。主要变化在于，原来存在多个侧边栏时，需要通过侧边栏顶部的下拉菜单切换，而现在会直接展示图标（跟 Edge 有点类似）。这样的好处是切换起来更方便了，缺点则是会挤占一整列的空间；并且如果装的扩展图标比较丑，比较有碍观瞻。另外，侧边栏周围多了一圈阴影装饰，营造出一个「悬浮」的视觉层级，至于好不好看就见仁见智了。</p>
<p data-omnivore-anchor-idx="33">因此，就现阶段而言，我建议对垂直标签栏感兴趣的朋友可以只打开 <code data-omnivore-anchor-idx="34" class="hljs language-css"><span data-omnivore-anchor-idx="35" class="hljs-selector-tag">sidebar</span><span data-omnivore-anchor-idx="36" class="hljs-selector-class">.revamp</span></code>，然后装一个 Tree Style Tab 之类的第三方扩展。这样，既可以获得新版侧边栏布局的便利，也可以用上比原生垂直标签栏更多的功能。至于原来的横向标签栏，可以通过 Firefix-UI-Fix 将其<a data-omnivore-anchor-idx="37" href="https://sspai.com/link?target=https%3A%2F%2Fgithub.com%2Fblack7375%2FFirefox-UI-Fix%2Fwiki%2FOptions%23tab-bar" target="_blank">设置为</a>自动隐藏、悬停显示。</p>
<figure data-omnivore-anchor-idx="38"><img data-omnivore-anchor-idx="39" data-omnivore-original-src="https://cdnfile.sspai.com/2024/10/17/article/830413b6cbf9644b98e0aff6548843b4.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,ssNtYmwhwiPQLLp1gEyoujyPNGJvC9QZhJn5eD5wiklc/https://cdnfile.sspai.com/2024/10/17/article/830413b6cbf9644b98e0aff6548843b4.png?imageView2/2/format/webp" data-original="https://cdnfile.sspai.com/2024/10/17/article/830413b6cbf9644b98e0aff6548843b4.png?imageView2/2/format/webp" data-index="1">
    <figcaption data-omnivore-anchor-idx="40">新版侧边栏布局搭配 Tree Style Tab 的效果</figcaption>
</figure>

<p data-omnivore-anchor-idx="41"><a data-omnivore-anchor-idx="42" data-mention="@化学心情下2" user-id="bs2od75b34tch2730oa0" href="https://sspai.com/u/liuxiaofengone">@化学心情下2</a>：一直以来 Windows 上的终端和类 Unux 上的都不太一样。当用户需要在类 Unix 终端里执行一个需要管理员权限的命令时，只需要将用户切换到 root 或者使用 sudo 命令（以 root 的身份）直接运行即可。</p>
<p data-omnivore-anchor-idx="43">但过去 Windows 上的终端，管理员身份和非管理员身份的终端窗口是明确分开的，微软表示：</p>
<blockquote data-omnivore-anchor-idx="44">
    <p data-omnivore-anchor-idx="45">PowerShell 不参与<a data-omnivore-anchor-idx="46" href="https://sspai.com/link?target=https%3A%2F%2Flearn.microsoft.com%2Fzh-cn%2Fwindows%2Fsecurity%2Fapplication-security%2Fapplication-control%2Fuser-account-control%2F" target="_blank">用户访问控制（UAC）。</a> 这意味着它无法提示用户对需要管理员批准的任务进行提升。</p>
    <p data-omnivore-anchor-idx="47">UAC 是一项 Windows 安全功能，可帮助防止恶意代码使用提升的权限运行。</p>
</blockquote>
<p data-omnivore-anchor-idx="48">在 24H2 之前需要使用管理员身份运行命令，主要有以下几种方法：</p>
<ol data-omnivore-anchor-idx="49">
    <li data-omnivore-anchor-idx="50">启用 Windows 终端时，手动选择「以管理员身份运行 PowerShell」；</li>
    <li data-omnivore-anchor-idx="51">使用 PowerShell 内置命令 <code data-omnivore-anchor-idx="52" class="hljs language-arduino language-crmsh">Start-<span data-omnivore-anchor-idx="53" class="hljs-built_in">Process</span></code>（或其简称 <code data-omnivore-anchor-idx="54" class="hljs language-autoit language-ebnf"><span data-omnivore-anchor-idx="55" class="hljs-built_in">runas</span></code>） 在命令中加入 <code data-omnivore-anchor-idx="56" class="hljs language-arduino language-autoit">Start-<span data-omnivore-anchor-idx="57" class="hljs-built_in">Process</span> powershell.exe -Verb RunAs -ArgumentList</code> 这样的命令额外弹出一个「以管理员身份运行」的 Powershell 运行后续命令；</li>
    <li data-omnivore-anchor-idx="58">在脚本中加入 <code data-omnivore-anchor-idx="59" class="hljs language-armasm language-diff">-<span data-omnivore-anchor-idx="60" class="hljs-keyword">NoProfile </span>-ExecutionPolicy <span data-omnivore-anchor-idx="61" class="hljs-keyword">Bypass</span></code> 这样的命令绕过 PowerShell 的执行策略和个人配置，进而弹出一个「以管理员身份运行」的 Powershell 运行后续命令。</li>
</ol>
<p data-omnivore-anchor-idx="62">换句话说，除非开始就「以管理员身份运行 PowerShell」，否则你后续你想执行一个需要管理员权限的命令，就绕不开重新打开一个 PowerShell 窗口的剧情。另外考虑到每次直接都默认以「以管理员身份运行 PowerShell」其实并不安全，很容易因为误操作或恶意脚本而对系统造成不必要的更改和破坏。所以这个设计对普通人影响不大，但对经常要和终端打交道的高级用户就很头疼了。虽然也存在一些第三方工具来模拟 sudo 的功能，例如 <a data-omnivore-anchor-idx="63" href="https://sspai.com/link?target=https%3A%2F%2Fgithub.com%2Fgerardog%2Fgsudo" target="_blank">gsudo</a> 和 <a data-omnivore-anchor-idx="64" href="https://sspai.com/link?target=https%3A%2F%2Fwww.nirsoft.net%2Futils%2Fnircmd2.html" target="_blank"><code data-omnivore-anchor-idx="65" class="hljs language-css language-stylus"><span data-omnivore-anchor-idx="66" class="hljs-selector-tag">nircmd</span><span data-omnivore-anchor-idx="67" class="hljs-selector-class">.exe</span> <span data-omnivore-anchor-idx="68" class="hljs-selector-tag">elevate</span></code></a>，但那毕竟需要额外安装。</p>
<p data-omnivore-anchor-idx="69">一直以为微软不再打算更改，结果在 Windows 11 24H2 里，微软终于引入了 Sudo for Windows 命令，来改善使用体验。</p>
<figure data-omnivore-anchor-idx="70"><img data-omnivore-anchor-idx="71" data-omnivore-original-src="https://cdnfile.sspai.com/2024/10/17/article/8653f40d9b50482ae24fcceaec95a5ec.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sg77VOJGkj_8MKiB9n1hFWk5lHKrKqIcL-D2IJZC1WMg/https://cdnfile.sspai.com/2024/10/17/article/8653f40d9b50482ae24fcceaec95a5ec.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" data-original="https://cdnfile.sspai.com/2024/10/17/article/8653f40d9b50482ae24fcceaec95a5ec.png?imageView2/2/format/webp" data-index="2"></figure>
<p data-omnivore-anchor-idx="72">想要使用这个功能，我们需要前往「设置 &gt; 系统 &gt; 开发者选项」，然后打开「启用 sudo」 开关；接着还可以配置 sudo 的运行模式：</p>
<figure data-omnivore-anchor-idx="73"><img data-omnivore-anchor-idx="74" data-omnivore-original-src="https://cdnfile.sspai.com/2024/10/17/article/dbccff5b16edaa7d4088dcb78f9bf099.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sm3osTW-7CLcPakt2F6qb4CuFz_mOX_R5UxG1mkRt8Fk/https://cdnfile.sspai.com/2024/10/17/article/dbccff5b16edaa7d4088dcb78f9bf099.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" data-original="https://cdnfile.sspai.com/2024/10/17/article/dbccff5b16edaa7d4088dcb78f9bf099.png?imageView2/2/format/webp" data-index="3"></figure>
<ul data-omnivore-anchor-idx="75">
    <li data-omnivore-anchor-idx="76">内联：类似 Linux 那样直接在当前终端窗口下提权；</li>
    <li data-omnivore-anchor-idx="77">新窗口：提权后需要另外打开一个窗口；</li>
    <li data-omnivore-anchor-idx="78">禁用输入：提升当前正在运行命令的权限，但阻止后续命令输入，相比内联模式更安全。</li>
</ul>
<figure data-omnivore-anchor-idx="79"><img data-omnivore-anchor-idx="80" data-omnivore-original-src="https://cdnfile.sspai.com/2024/10/17/article/572b14a100ba971bedc34db13ec32c4f.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sU9rv7laYSD6XpWIJlon_3wnE5c8GvaV1W6XoMPFpIVM/https://cdnfile.sspai.com/2024/10/17/article/572b14a100ba971bedc34db13ec32c4f.png?imageView2/2/format/webp" data-original="https://cdnfile.sspai.com/2024/10/17/article/572b14a100ba971bedc34db13ec32c4f.png?imageView2/2/format/webp" data-index="4"></figure>
<p data-omnivore-anchor-idx="81">使用上 Sudo for Windows 和类 Unix 的 sudo 命令大致类似，碰到 Windows 终端告诉你权限不足的地方，前面加上 sudo 重新运行一次即可。</p>
<p data-omnivore-anchor-idx="82">不过需要注意的是，Sudo for Windows 距离现有的 Start-Process (runas) 和「正版」sudo 都有一些差距。例如，它不能像 runas 那样切换为任意用户，输入密码也需要弹出 UAC 对话框而不是直接在命令行中完成。而与 sudo 相比，它并不支持通过 <code data-omnivore-anchor-idx="83" class="hljs language-ebnf language-matlab"><span data-omnivore-anchor-idx="84" class="hljs-attribute">sudo -i</span></code> 或者 <code data-omnivore-anchor-idx="85" class="hljs language-ebnf language-nginx"><span data-omnivore-anchor-idx="86" class="hljs-attribute">sudo su</span></code> 直接切换成超级管理员用户，而是只能提权单个命令。（当然，它更不可能有正版 sudo 那句<a data-omnivore-anchor-idx="87" href="https://sspai.com/link?target=https%3A%2F%2Fxkcd.com%2F838%2F" target="_blank">吓人的报错提示</a>。）</p>
<p data-omnivore-anchor-idx="88">你可以通过微软的<a data-omnivore-anchor-idx="89" href="https://sspai.com/link?target=https%3A%2F%2Flearn.microsoft.com%2Fen-us%2Fwindows%2Fsudo%2F" target="_blank">文档页面</a>了解更多关于 Windows 版 sudo 的细节。</p>
<h2 data-omnivore-anchor-idx="90">Windows HDR 壁纸支持来了，但需要一些设置技巧</h2>
<p data-omnivore-anchor-idx="91"><a data-omnivore-anchor-idx="92" data-mention="@克莱德" user-id="bs2p00tb34tch278ngkg" href="https://sspai.com/u/clyde">@克莱德</a>：在 Windows 11 24H2 中，你可以将一张 HDR 图片设置为壁纸——这听起来是不是很酷？微软也这么觉得。所以尽管这个功能从 2023 年 <a data-omnivore-anchor-idx="93" href="https://sspai.com/link?target=https%3A%2F%2Fwww.windowscentral.com%2Fsoftware-apps%2Fwindows-11%2Fwindows-11-is-getting-true-hdr-desktop-wallpaper-support-and-better-screen-casting" target="_blank">8 月</a>就开始内部测试了、尽管有一个非常可笑的 bug 几乎半年以前就有人发现了，在 24H2 正式版中我们还是迎来了这样一个实用性几乎为零、同时还存在低级问题的特性。</p></article>    </div> <div data-omnivore-anchor-idx="94" data-v-114a0539="" data-v-7d731348=""><p data-omnivore-anchor-idx="95">
