<h2 data-omnivore-anchor-idx="13">Chrome 内置 Gemini Nano 模型上线</h2>
<p data-omnivore-anchor-idx="14"><a data-omnivore-anchor-idx="15" data-mention="@PlatyHsu" user-id="bs2p0qtb34tch278vgn0" href="https://sspai.com/u/platyhsu">@PlatyHsu</a>: <a data-omnivore-anchor-idx="16" href="https://developer.chrome.com/docs/ai/built-in">Chrome 内置 AI 模型</a>是今年 Google I/O 上<a data-omnivore-anchor-idx="17" href="https://io.google/2024/explore/47fc6e98-8359-4be0-b9b9-4bc7b28bd063/">揭晓</a>的 AI 相关新功能之一。从 Chrome 127（6 月 12 日进入测试通道）起，这个功能已经可以使用了。目前，用于支撑这个功能的模型是谷歌 Gemini 系列中最小的 Nano 版本，这也是 <a data-omnivore-anchor-idx="18" href="https://developer.android.com/ai/generativeai">Android 内置 AI</a> 选用的模型。</p>
<figure data-omnivore-anchor-idx="19"><img data-omnivore-anchor-idx="20" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/05/article/a9491edb7865a355a06dfa48be79c38a.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,slX-4AGWPC0tKG6C-vFDPLUOaVpwOiT7_LNIo2BdE4fY/https://cdnfile.sspai.com/2024/07/05/article/a9491edb7865a355a06dfa48be79c38a.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" data-original="https://cdnfile.sspai.com/2024/07/05/article/a9491edb7865a355a06dfa48be79c38a.png?imageView2/2/format/webp">
    <figcaption data-omnivore-anchor-idx="21">Chrome 内置 AI 架构（来源：谷歌）</figcaption>
</figure>
<p data-omnivore-anchor-idx="22">根据<a data-omnivore-anchor-idx="23" href="https://docs.google.com/document/d/1VG8HIyz361zGduWgNG7R_R8Xkv0OOJ8b5C9QKeCjU0c/view">官方说明</a>，启用 Chrome 内置 AI 的步骤如下：</p>
<ol data-omnivore-anchor-idx="24">
    <li data-omnivore-anchor-idx="25">确保安装了 Chrome 127 或以上版本（目前尚未发布正式版，因此需安装 Dev 或 Canary 通道版本），并确保有 22GB 以上空余硬盘空间；</li>
    <li data-omnivore-anchor-idx="26">打开 <code data-omnivore-anchor-idx="27" class="hljs language-applescript language-avrasm"><span data-omnivore-anchor-idx="28" class="hljs-keyword">about</span>:flags</code> 页面，调整以下选项，并重启 Chrome——<ul data-omnivore-anchor-idx="29">
            <li data-omnivore-anchor-idx="30"><code data-omnivore-anchor-idx="31" class="hljs language-applescript language-livecodeserver">optimization-guide-<span data-omnivore-anchor-idx="32" class="hljs-keyword">on</span>-device-model</code> 设置为 Enabled BypassPerfRequirement；</li>
            <li data-omnivore-anchor-idx="33"><code data-omnivore-anchor-idx="34" class="hljs language-ebnf language-maxima"><span data-omnivore-anchor-idx="35" class="hljs-attribute">prompt-api-for-gemini-nano</span></code> 设置为 Enabled；</li>
        </ul>
    </li>
    <li data-omnivore-anchor-idx="36">在任意页面打开 DevTools（即在页面空白处点击右键，选择「检查元素」），然后切换到 Console 选项卡，输入以下语句并回车执行：<code data-omnivore-anchor-idx="37" class="hljs language-coffeescript language-css"><span data-omnivore-anchor-idx="38" class="hljs-keyword">await</span> <span data-omnivore-anchor-idx="39" class="hljs-built_in">window</span>.ai.createTextSession();</code>。这是为了触发模型下载，目前返回错误是正常的。</li>
    <li data-omnivore-anchor-idx="40">打开 <code data-omnivore-anchor-idx="41" class="hljs language-applescript language-avrasm"><span data-omnivore-anchor-idx="42" class="hljs-keyword">about</span>:components</code> 页面，此时应当能看到一项 Optimization Guide On Device Model，其右侧版本号不为空（否则可以点击下面 Check for update 按钮手动刷新）。这个组件首次使用时需要下载一个大约 1.28GB 的模型文件，当其状态显示为 Up-to-date 时即为下载完成。</li>
    <li data-omnivore-anchor-idx="43">此时回到 DevTools，在控制台中执行 <code data-omnivore-anchor-idx="44" class="hljs language-coffeescript language-css"><span data-omnivore-anchor-idx="45" class="hljs-keyword">await</span> <span data-omnivore-anchor-idx="46" class="hljs-built_in">window</span>.ai.canCreateTextSession();</code> 如返回 <code data-omnivore-anchor-idx="47" class="hljs language-ebnf"><span data-omnivore-anchor-idx="48" class="hljs-attribute">readily</span></code> 即说明启用成功。</li>
</ol>
<p data-omnivore-anchor-idx="49">（其中，第 3 步是很多现有文章没有提到的，我在启用过程中也卡在这步比较久，提醒遇到类似问题的读者注意。）</p>
<p data-omnivore-anchor-idx="50">需要指出，目前 Chrome 只是开放了一套 Prompt API 供网页或插件使用，但没有提供任何基于 Gemini Nano 的内置功能。一份不太完整的 Prompt API <a data-omnivore-anchor-idx="51" href="https://github.com/explainers-by-googlers/prompt-api">文档</a>可以在 Chrome 团队的 GitHub 找到，简言之——</p>
<ul data-omnivore-anchor-idx="52">
    <li data-omnivore-anchor-idx="53">Chrome 现在提供一个 <code data-omnivore-anchor-idx="54" class="hljs language-ebnf"><span data-omnivore-anchor-idx="55" class="hljs-attribute">ai</span></code> 接口用于执行端侧模型请求。网页和插件可以使用 <code data-omnivore-anchor-idx="56" class="hljs language-stylus language-isbl"><span data-omnivore-anchor-idx="57" class="hljs-function"><span data-omnivore-anchor-idx="58" class="hljs-title">canCreateTextSession</span><span data-omnivore-anchor-idx="59" class="hljs-params">()</span></span></code> 来检查浏览器是否支持该功能。</li>
    <li data-omnivore-anchor-idx="60">与模型的交互是在会话（session）中完成的。为此，首先要用 <code data-omnivore-anchor-idx="61" class="hljs language-stylus language-isbl"><span data-omnivore-anchor-idx="62" class="hljs-function"><span data-omnivore-anchor-idx="63" class="hljs-title">createTextSession</span><span data-omnivore-anchor-idx="64" class="hljs-params">()</span></span></code> 方法创建一个会话，在此过程中可以选填的参数包括 <code data-omnivore-anchor-idx="65" class="hljs language-ebnf"><span data-omnivore-anchor-idx="66" class="hljs-attribute">systemPrompt</span></code>（系统提示词，字符串）、<code data-omnivore-anchor-idx="67" class="hljs language-ebnf"><span data-omnivore-anchor-idx="68" class="hljs-attribute">initialPrompts</span></code>（现有提示词，数组）、<code data-omnivore-anchor-idx="69" class="hljs language-ebnf"><span data-omnivore-anchor-idx="70" class="hljs-attribute">temperature</span></code> 和 <code data-omnivore-anchor-idx="71" class="hljs language-ebnf"><span data-omnivore-anchor-idx="72" class="hljs-attribute">topK</span></code>（两个控制模型「自由发挥」的常见参数）。</li>
    <li data-omnivore-anchor-idx="73">要从模型获得输出，通过会话的 <code data-omnivore-anchor-idx="74" class="hljs language-stylus language-isbl"><span data-omnivore-anchor-idx="75" class="hljs-function"><span data-omnivore-anchor-idx="76" class="hljs-title">prompt</span><span data-omnivore-anchor-idx="77" class="hljs-params">()</span></span></code> 方法发送提示词，或者用 <code data-omnivore-anchor-idx="78" class="hljs language-stylus language-isbl"><span data-omnivore-anchor-idx="79" class="hljs-function"><span data-omnivore-anchor-idx="80" class="hljs-title">promptStreaming</span><span data-omnivore-anchor-idx="81" class="hljs-params">()</span></span></code> 方法获得流式输出（「打字机」效果）。</li>
    <li data-omnivore-anchor-idx="82">已创建的会话可以用 <code data-omnivore-anchor-idx="83" class="hljs language-stylus language-isbl"><span data-omnivore-anchor-idx="84" class="hljs-function"><span data-omnivore-anchor-idx="85" class="hljs-title">clone</span><span data-omnivore-anchor-idx="86" class="hljs-params">()</span></span></code> 方法复制，以及用 <code data-omnivore-anchor-idx="87" class="hljs language-stylus language-isbl"><span data-omnivore-anchor-idx="88" class="hljs-function"><span data-omnivore-anchor-idx="89" class="hljs-title">destroy</span><span data-omnivore-anchor-idx="90" class="hljs-params">()</span></span></code> 方法删除。</li>
</ul>
<p data-omnivore-anchor-idx="91">（你也可以查阅 AI 模块的<a data-omnivore-anchor-idx="92" href="https://source.chromium.org/chromium/chromium/src/+/main:third_party/blink/renderer/modules/ai/">代码</a>或者在控制台输入 <code data-omnivore-anchor-idx="93" class="hljs language-ebnf"><span data-omnivore-anchor-idx="94" class="hljs-attribute">ai</span></code> 来了解其支持的方法。）</p>
<figure data-omnivore-anchor-idx="95"><img data-omnivore-anchor-idx="96" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/05/article/5bf55a8527d0c7071396e8767fd2eae8.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sc7Ty8_jpnvonYTdxCylD-ZPSVXS68Ynpyl_XrB9QEPI/https://cdnfile.sspai.com/2024/07/05/article/5bf55a8527d0c7071396e8767fd2eae8.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" data-original="https://cdnfile.sspai.com/2024/07/05/article/5bf55a8527d0c7071396e8767fd2eae8.png?imageView2/2/format/webp"></figure>
<p data-omnivore-anchor-idx="97">例如，要从当前网页获取文章正文，并通过 Gemini Nano 总结，可以在控制台运行以下代码：</p>
<pre data-omnivore-anchor-idx="98"><code data-omnivore-anchor-idx="99" class="hljs language-dart language-javascript"><span data-omnivore-anchor-idx="100" class="hljs-keyword">const</span> article = <span data-omnivore-anchor-idx="101" class="hljs-built_in">document</span>.<span data-omnivore-anchor-idx="102" class="hljs-built_in">querySelector</span>(<span data-omnivore-anchor-idx="103" class="hljs-string">"article"</span>).innerText;

<span data-omnivore-anchor-idx="104" class="hljs-keyword">const</span> session = <span data-omnivore-anchor-idx="105" class="hljs-keyword">await</span> ai.createTextSession({
  systemPrompt: <span data-omnivore-anchor-idx="106" class="hljs-string">"Summarize the article provided by the user, maintaining the original language of the article. The summary should capture key points and main ideas, using bullet points for clarity and conciseness. Ensure the summary is no longer than 5-7 bullet points, covering the introduction, key arguments, and conclusion."</span>
});

<span data-omnivore-anchor-idx="107" class="hljs-keyword">const</span> result = <span data-omnivore-anchor-idx="108" class="hljs-keyword">await</span> session.prompt(article);
console.log(result);</code></pre>
<p data-omnivore-anchor-idx="109">我用了少数派最近一篇大约六千字的<a data-omnivore-anchor-idx="110" href="https://sspai.com/prime/story/ppc-history-11">文章</a>做测试。在一台 MacBook Air (M2, 2022) 上运行代码大约花费了 15 秒；在此期间，Chrome 的 CPU 占用率从 1.1% 提高到 4.6%，内存占用增加了大约 1.1GB，应该说是比较轻量的，对大多数当代电脑配置压力不大。</p>
<p data-omnivore-anchor-idx="111">不过，限于 Gemini Nano 模型的能力（也可能是我使用姿势不对？），获得的效果有点一言难尽，并且还出现了幻觉。</p>
<figure data-omnivore-anchor-idx="112"><img data-omnivore-anchor-idx="113" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/05/article/7b871ec11e7777daedff1318296d2559.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,se_jj33Irg14FALLgtNgvMBhiwFHD3c8JacVAGdGa1Bg/https://cdnfile.sspai.com/2024/07/05/article/7b871ec11e7777daedff1318296d2559.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" data-original="https://cdnfile.sspai.com/2024/07/05/article/7b871ec11e7777daedff1318296d2559.png?imageView2/2/format/webp"></figure>
<p data-omnivore-anchor-idx="114">如果你不想自己写代码，也有一些现成项目可以用对话式界面来和内置 AI 交互，例如 Lightning Joyce 的 <a data-omnivore-anchor-idx="115" href="https://chromeai.co/">chromeai.co</a>。我因为不是很死心，又挑了几个这两天问过 GPT 的问题来问 Gemini Nano。结果……请大家自己判断。</p>
<figure data-omnivore-anchor-idx="116"><img data-omnivore-anchor-idx="117" data-omnivore-original-src="https://cdnfile.sspai.com/2024/07/05/article/f08465972d26e6c7b848c8504c961577.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sziGHG4Uz--U2hrG4HdkxsRClSXqX6p0f2XH3GqIB-gw/https://cdnfile.sspai.com/2024/07/05/article/f08465972d26e6c7b848c8504c961577.png?imageView2/2/w/1120/q/40/interlace/1/ignore-error/1/format/webp" data-original="https://cdnfile.sspai.com/2024/07/05/article/f08465972d26e6c7b848c8504c961577.png?imageView2/2/format/webp">

<p data-omnivore-anchor-idx="119">但这个效果倒也不完全出乎意料。根据谷歌此前提供的 <a data-omnivore-anchor-idx="120" href="https://arxiv.org/pdf/2312.11805">Gemini 模型信息</a>，Nano 有 1.8B 和 3.25B 参数两种版本，均采用 4-bit 量化。从下载尺寸看，Chrome 中用的应该是 1.8B 版本。至于实际性能，由于谷歌并未提供 Gemini Nano 的 API，没有太多可供参考的测试成绩，唯一有一定可比性的通用测试是 MMLU (5-shot)，谷歌公布的成绩是 45.9。与其他几个热门轻量模型对比，Phi-3 Mini (3.8B) 的成绩是 68.8，Mistral 7B 是 60.1，Llama 3 8B 是 68.4（来自各自官方数据）。</p>
<p data-omnivore-anchor-idx="121">诚然，这个对比不太公平，但考虑到 7B 尺寸的模型在很多电脑上也能跑得起来，在线模型也越来越便宜，对于其实没那么看重本地运行隐私性的日常用户而言，Gemini Nano 的竞争力确实不太高（君不见当初有多少人哭着喊着想要在隐私地狱 Bing 开通 GPT-4），唯一有优势的可能就是 32K 的上下文窗口了。不过 Chrome 内置 AI 据谷歌说法是一个通用框架，理论上可以接入更多模型，这就有待后续观察了。</p>
<h2 data-omnivore-anchor-idx="122">Windows 11 的广告更多了</h2>
<p data-omnivore-anchor-idx="123"><a data-omnivore-anchor-idx="124" data-mention="@克莱德" user-id="bs2p00tb34tch278ngkg" href="https://sspai.com/u/clyde">@克莱德</a>：下次遇到「什么系统广告最多」这个话题，讨论的时候别忘了带上 Windows 11。</p>
<p data-omnivore-anchor-idx="125">在早前的首页文章中我们有提到，部分 Windows 11 的广告是关不掉的，比如设置页面中的 Copilot 推广。或许微软也知道系统设置是块「风水宝地」，在近期推送给稳定通道的 <a data-omnivore-anchor-idx="126" href="https://support.microsoft.com/zh-cn/topic/2024-%E5%B9%B4-6-%E6%9C%88-25-%E6%97%A5-kb5039302-%E6%93%8D%E4%BD%9C%E7%B3%BB%E7%BB%9F%E5%86%85%E9%83%A8%E7%89%88%E6%9C%AC-22621-3810-%E5%92%8C-22631-3810-%E9%A2%84%E8%A7%88%E7%89%88-0ab34e3f-bca9-4a52-a1a4-404bf8162f58">KB5039302</a> 更新中，已登录微软账号且「主动在设备上玩游戏」的用户还将看到 Xbox Game Pass 的广告……大概长这个样子：</p>

<p data-omnivore-anchor-idx="129">这还没完——最近采用新设计的 Windows 11 天气应用也已经开始推送了，新设计谈不上惊艳，倒是让原本嵌入在信息流里的广告卡片更加直观了。一般而言，你能在当前天气状态和详细信息两个区域找到两个固定的广告位——体验与部分国产 Android 定制系统看齐。</p>
