的使用，例如使用 TWRP 刷机</li></ul><h2 data-omnivore-anchor-idx="29" id="ss-hId-1" hid="ss-hId-1">背景：为什么我会选择类原生固件？</h2><p data-omnivore-anchor-idx="30">在 Android 普及初期，「刷机」是玩机发烧友们必备的技能，也是拿到设备后必做的工作。那时部分设备官方固件不好用，于是一些技术大神组成团队，制作了以 Cyanogen Mod 为代表的第三方类原生 ROM，繁荣了 Android 的生态，发掘设备的潜力。</p><p data-omnivore-anchor-idx="31">时过境迁，随着手机厂商的发力，主流厂商的官方固件已经足够强大，尤其是 MIUI、HarmonyOS 等优秀作品，早已了却当年发烧友们曾面对的种种遗憾。刷机时代就这么成为历史：更多的用户选择安心使用官方 ROM「养老」，当年遍寻刷机包的盛况已不再。</p><p data-omnivore-anchor-idx="32">然而手机厂商总是要推陈出新的。以小米 6<sup data-omnivore-anchor-idx="33" data-omnivore-anchor-idx="35">感兴趣的读者可以读读知乎博主【科技好兄der】的这篇文章：《换新不换旧，除非小米6？这三大手机品牌的钉子户，有你吗？》。</p></div></sup>为代表的优秀产品，硬件依然能打，骁将不老，厂商却不再提供官方固件的新版适配。好在玩家和第三方 ROM data-omnivore-anchor-idx="82">类原生 ROM 的最大优势就是干干净净，体积小、无捆绑、无广告。不过，它们虽然能让老机器吃上新版 Android，新版本未必能与「好用」完全划上等号。</p><p data-omnivore-anchor-idx="83">手机厂商的固件，一般都做足了功能优化，拥有开箱即用的自带应用，并针对国内用户提供各类特色功能。例如：</p><ul data-omnivore-anchor-idx="84"><li data-omnivore-anchor-idx="85">云同步</li><li data-omnivore-anchor-idx="86">自带的天气应用</li><li data-omnivore-anchor-idx="87">验证码自动识别</li><li data-omnivore-anchor-idx="88">自带手机管家功能</li><li data-omnivore-anchor-idx="89">游戏优化（尤其是 MIUI 与 HarmonyOS）</li></ul><p data-omnivore-anchor-idx="90">然而，类原生固件是不具备上述功能的，自带应用「少得可怜」，像是最基本的天气应用都没有提供。对于手机的重度用户来说，实用功能的缺失，的确给手机的使用带来不便，或许也是类原生 ROM 用户群体不大的原因。</p><p data-omnivore-anchor-idx="91">幸运的是，得益于一系列优秀的应用程序，配合适当的优化策略，类原生 ROM 的局限性将不再是硬伤。遵循接下来的「破局」策略，你将会收获一个完全胜任当下日常使用的固件。</p><h2 data-omnivore-anchor-idx="92" id="ss-hId-3" hid="ss-hId-3">系统的基本优化</h2><p data-omnivore-anchor-idx="93">就笔者的经验来看，类原生固件要想用的舒服，Root 权限必不可少，这样才能用上诸多有利于改善系统体验的软件与特性。在此基础上，再安装 Shizuku Manager，可以解锁一些系统管理工具的潜能，进而激发手机自身的潜力。</p><p data-omnivore-anchor-idx="94">另一方面，类原生固件开发者以海外为主，会存在一些网络配置问题（如下文所说的 Captive Portal），这类问题也需要解决。</p><h3 data-omnivore-anchor-idx="95">1）借助 Magisk 获取 Root 权限</h3><p data-omnivore-anchor-idx="96">刷类原生 ROM 的一大意义，在于解锁 Root 权限，定制系统为我所用。</p><p data-omnivore-anchor-idx="97">自 Android 8.0 开始，手机 Root 的首选方式是安装 <strong data-omnivore-anchor-idx="98">Magisk</strong>。这是由 Topjohnwu 开发的框架，可以在不修改系统文件的情况下，解锁手机的 Root 权限，还提供模块安装、Zygisk（一套允许进一步修改系统的框架）等高级特性。</p><p data-omnivore-anchor-idx="99"><strong data-omnivore-anchor-idx="100">安装 Magisk 不是本文重点，这里不赘述。</strong><a data-omnivore-anchor-idx="101" href="https://sspai.com/link?target=https%3A%2F%2Ftopjohnwu.github.io%2FMagisk%2Finstall.html" target="_blank"><strong data-omnivore-anchor-idx="102">具体的安装方法可以参考官方教程（英文）</strong></a>，也可自行寻找中文教程。</p><p data-omnivore-anchor-idx="103">编注：除了 Magisk，Kernel SU 也是当下玩机社区的 root 方案之一，详见《<a Portal（强制门户）地址</h3><p data-omnivore-anchor-idx="110">刷类原生固件的玩家，在连接国内网络时，或许会看到 4G/5G 或 Wi-Fi 图标上有一个「感叹号」，并且系统会不时提示「当前网络无法连接互联网」。然而此时手机仍能正常上网。</p><p data-omnivore-anchor-idx="111">这是因为 Android 会在连接网络时，通过访问 Captive Portal 服务器来确认网络是否能正常使用。该服务器会返回 HTTP 204 代码，以告知用户当前的网络是可用的。</p><p data-omnivore-anchor-idx="112">但是，类原生 ROM 多为国外开发团队的作品，固件使用的 Captive Portal 服务器是谷歌的，显然无法直接连接。因此，你需要使用一款软件——CaptiveMgr，将 Captive Portal 的地址设为其他可用的服务器。</p><p data-omnivore-anchor-idx="113"><strong data-omnivore-anchor-idx="114">第一步：</strong>可以从 <a data-omnivore-anchor-idx="115" Root 权限。</p><figure data-omnivore-anchor-idx="119"><img data-omnivore-anchor-idx="120" 前，需要先授权</figcaption></figure><p data-omnivore-anchor-idx="122"><strong data-omnivore-anchor-idx="123">第三步，</strong>下滑到「Captive Portal 服务器」一栏，在「备选服务器」中选择前四个服务器中的一个。笔者推荐选择 MIUI 服务器</figcaption></figure><p data-omnivore-anchor-idx="127">重新手动连接网络（如开关 Wi-Fi、开关飞行模式），或点击最下方的「刷新图标」按钮，即可生效。这样，烦人的感叹号就不再出现。</p><h3 data-omnivore-anchor-idx="128">3）配置 Shizuku</h3><p data-omnivore-anchor-idx="129">高阶玩家往往离不开 Shizuku。它可以让用户直接使用系统 API，而无需频繁通过 Root 权限命令<code data-omnivore-anchor-idx="130" class="hljs language-ebnf language-stata"><span data-omnivore-anchor-idx="131" class="hljs-attribute">su</span></code>来进行调用（这会导致性能开销，且频繁使用会导致易用性打折扣），还拥有比 Shell 更高的性能。<sup data-omnivore-anchor-idx="132" href="https://shizuku.rikka.app/zh-hans/" footnote-id="3" data-title="引自Shizuku官方网站。">3</sup></p><p data-omnivore-anchor-idx="133">很多软件能够充分利用 Shizuku 来改善用户体验。举 3 个例子：</p><ul data-omnivore-anchor-idx="134"><li data-omnivore-anchor-idx="135">MT 管理器、存储空间清理（开发者枯藤老树出品）可利用 Shizuku 来访问<code data-omnivore-anchor-idx="136" class="hljs language-awk language-dts"><span data-omnivore-anchor-idx="137" class="hljs-regexp">/sdcard/</span>Android<span data-omnivore-anchor-idx="138" class="hljs-regexp">/</span></code>等受限目录</li><li data-omnivore-anchor-idx="139">Aurora Store、Droidfy 等应用管理工具可利用 Shizuku 实现静默安装</li><li data-omnivore-anchor-idx="140">软件冻结工具「雹」可利用 Shizuku 来快速冻结/解冻应用</li></ul><p data-omnivore-anchor-idx="141">在已经获得 Root 权限的手机上，配置 Shizuku 只需两步。</p><p data-omnivore-anchor-idx="142"><strong
