data-omnivore-anchor-idx="35" href="https://sspai.com/link?target=https%3A%2F%2Fplay.google.com%2Fstore%2Fapps%2Fdetails%3Fid%3Dio.github.mthli.snapseek" target="_blank">Snapseek</a> 应该是当下「没有之一」的、最好的选择。</p><p data-omnivore-anchor-idx="36">这里还是照顾下没空看开头以及上面那一堆关联阅读文章的朋友解释一下：Snapseek 是用来干嘛的？</p><blockquote data-omnivore-anchor-idx="37"><p data-omnivore-anchor-idx="38">昨天刷 Twitter 的时候好像看到有人针对微软的「召回」功能问了类似的问题，下面有条回复很好地解答了这个问题，怎么说的来着……？</p></blockquote><p data-omnivore-anchor-idx="39">Snapseek 解决的正是这个问题。只需打开 Snapseek，将脑海中残余的关键字 Recall 输入搜索框，然后就能找到包含目标内容的那张截图了（哦原来就是我自己说的）。</p><figure data-omnivore-anchor-idx="40"><img data-omnivore-anchor-idx="41" data-omnivore-original-src="https://cdnfile.sspai.com/editor/u_/cp81lflb34t8oib45rk0.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,s-kThHjAK89MMB3rIyiHoU3zdmzVDZNGw1NFeWP7_zmE/https://cdnfile.sspai.com/editor/u_/cp81lflb34t8oib45rk0.png?imageView2/2/format/webp" alt="WThWbhDHXoHaZkxocIscQ6IrnGd" data-original="https://cdnfile.sspai.com/editor/u_/cp81lflb34t8oib45rk0.png?imageView2/2/format/webp" data-index="1"><figcaption data-omnivore-anchor-idx="42">找到那条「我好像在哪里看过」的内容，就是 Snapseek 的核心功能</figcaption></figure><p data-omnivore-anchor-idx="43">虽然要在 Android 平台上实现这个功能，就不可避免地要和无障碍、后台运行、前台服务等「高危」权限打交道，但 Snapseek 在隐私数据处理方面做得还算合格：截图存储在本地、OCR 识别基于本地模型、联网功能也仅限 Google Play 结算系统验证。</p><p data-omnivore-anchor-idx="44">最重要的是，和 Rewind、Recall 采用的全盘记录、手动排除例外的思路不同，Snapseek 的设定方式完全相反——你得手动选择特定的 app 才能开启截屏记录。虽然本质上来说是同一种打法的正反手，由于 Android 系统无障碍识屏速度的问题偶尔也有范围溢出的情况（比如上图的通知中心），但体验和观感上个人还是更认可 Snapseek 这种做法的。目前 Snapseek 目前唯一的内购也设置在这里。免费版用户只能选择两个应用进行记录，想要扩大记录范围则需要 3.99 美元解锁高级版。</p><figure data-omnivore-anchor-idx="45"><img data-omnivore-anchor-idx="46" data-omnivore-original-src="https://cdnfile.sspai.com/editor/u_/cp81lftb34t8oib45rkg.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,spMBKMtLr0vm5YwlWn8sAZwlrgwXGW_VNu6GLkbee9W0/https://cdnfile.sspai.com/editor/u_/cp81lftb34t8oib45rkg.png?imageView2/2/format/webp" alt="UvtgbAITuoSlWDxypZlcygFMn6f" data-original="https://cdnfile.sspai.com/editor/u_/cp81lftb34t8oib45rkg.png?imageView2/2/format/webp" data-index="2"></figure><p data-omnivore-anchor-idx="47">和 Windows「召回」功能对大部分 Chromium 浏览器不同的是，Snapseek 对浏览器链接和 app <a data-omnivore-anchor-idx="48" href="https://sspai.com/link?target=https%3A%2F%2Fdeveloper.android.com%2Ftraining%2Fapp-links%2Fdeep-linking" target="_blank">深度链接</a>的支持还十分有限。举个例子，如果你选择了浏览器进行记录，那么 Snapseek 会基于无障碍的屏幕内容读取功能获取对应页面的链接，这样我们在索引相关内容时就能点击链接跳转回对应页面——这种实现方案的弊端自然也很明显，要是你浏览时地址栏因为各种原因隐藏了，Snapseek 就抓不到对应的链接了。</p><figure data-omnivore-anchor-idx="49"><img data-omnivore-anchor-idx="50" data-omnivore-original-src="https://cdnfile.sspai.com/editor/u_/cp81lg5b34t8og10dvn0.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sKnGjCVc-rOnToK_-oCCqWenU-J2E7tzBWKa85bfjDNI/https://cdnfile.sspai.com/editor/u_/cp81lg5b34t8og10dvn0.png?imageView2/2/format/webp" alt="Yn45bWLDOoePSPx4A6bc4TrpnXf" data-original="https://cdnfile.sspai.com/editor/u_/cp81lg5b34t8og10dvn0.png?imageView2/2/format/webp" data-index="3"><figcaption data-omnivore-anchor-idx="51">同一个页面能提取和不能提取到链接都是有可能的</figcaption></figure><p data-omnivore-anchor-idx="52">想要通过记录的截图跳转到应用对应的界面同理也是不行的。这两个问题或许都有更好的解决方案，比如 Pixel Launcher 在多任务界面就能自动提取部分页面的超链接用于分享，只是不太清楚<a data-omnivore-anchor-idx="53" href="https://sspai.com/link?target=https%3A%2F%2Fdeveloper.android.com%2Fguide%2Fcomponents%2Factivities%2Frecents%23url-sharing" target="_blank">背后的 API</a>目前是否已经开放给了第三方。</p><p data-omnivore-anchor-idx="54">除此之外，在索引方面 Snapseek 目前的设定有些容易让人感到迷惑。比如应用设置中的「文本识别」选项支持中、日、韩三种语言和拉丁文识别，并且仅支持单选，但我在中文和英文环境下实测发现好像无论设置什么语言影像都不算大，搜索中文和英文都能得到想找的结果。</p><p data-omnivore-anchor-idx="55">AI 方面，在刚刚更新的版本中 Snapseek 加入了基于 Gemini API 的屏幕翻译功能，设置引导做得简单易懂，但使用效果受限于 Gemini API 可用性并且视觉、交互体验都比较一般（它甚至会翻译我的状态栏）；相比之下我更希望未来能在 Snapseek 上看到基于 Gemini Nano 本地模型的自然语义搜索，毕竟「欸我之前看到了一个什么什么内容」这种表述更符合我们的检索直觉。</p><figure data-omnivore-anchor-idx="56"><img data-omnivore-anchor-idx="57" data-omnivore-original-src="https://cdnfile.sspai.com/2024/05/24/940b597287b42317aae4ec2809061862.png?imageView2/2/format/webp" src="https://proxy-prod.omnivore-image-cache.app/0x0,sv67rNEDKtg1evMTsVxhOX54CHP2qrpRXtfdPLzAfHh8/https://cdnfile.sspai.com/2024/05/24/940b597287b42317aae4ec2809061862.png?imageView2/2/format/webp" data-original="https://cdnfile.sspai.com/2024/05/24/940b597287b42317aae4ec2809061862.png?imageView2/2/format/webp" data-index="4"><figcaption data-omnivore-anchor-idx="58">基于 Gemini API 的泡泡翻译功能以及翻译效果</figcaption></figure><p data-omnivore-anchor-idx="59">最后，Snapseek 虽然一直在后台给我们选中的 app 截图，但应用设置内提供了保存为灰度图的选项并且可以手动选择截图分辨率和保存时长，在主流 Android 设备上应该不会带来什么存储空间压力。</p><p
