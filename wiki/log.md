# 操作日志

这是知识库的所有摄入、查询、维护记录的时间线。

## 使用说明

每次执行以下操作时，在此文件添加对应条目：

### 摄入 (Ingest)
格式：
```markdown
## 摄入 - YYYY-MM-DD

**来源**：[原始资料名称](raw/路径)
**处理摘要**：[AI 对这份资料做了什么]
**创建/更新页面**：
- [[页面名称]]
**备注**：[任何需要记录的信息]
```

### 查询 (Query)
格式：
```markdown
## 查询 - YYYY-MM-DD

**问题**：[用户的问题]
**参考页面**：
- [[页面名称]]
**答案摘要**：[AI 的回答要点]
**归档**：[如果答案有价值，是否保存为新页面]
```

### 维护 (Lint)
格式：
```markdown
## 维护 - YYYY-MM-DD

**检查项**：
- [ ] 矛盾检查
- [ ] 过时观点更新
- [ ] 缺失页面识别
- [ ] 孤立页面检查
- [ ] 知识空白补充
**发现的问题**：[列出发现的问题]
**采取的行动**：[采取的维护措施]
```
