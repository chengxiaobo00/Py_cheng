# 知识管理

## 概述

知识管理的核心命题：如何让今天的探索成为明天的基础设施，避免知识重复劳动，实现认知复利。

## 知识管理的演进

### 第一阶段：传统笔记
- 手动记录、分类整理
- 问题：检索困难、连接缺失

### 第二阶段：RAG（检索增强生成）
- AI 检索文档片段，临时综合生成答案
- 问题：没有沉淀、每次从零开始

### 第三阶段：LLM-Wiki
- AI 持续维护结构化知识库
- 优势：复利增长、交叉引用、矛盾检测、自我进化

## LLM-Wiki 核心原则

1. **不可变来源**：原始资料永不被修改
2. **AI 所有权**：AI 完全负责 Wiki 层的组织和维护
3. **结构化编译**：原始文档 → 实体页面 + 主题综述 + 对比分析
4. **持久归档**：有价值的内容永不消失于聊天历史
5. **定期维护**：健康检查确保知识质量

## 工具选择

- **文件格式**：Markdown（AI 原生、可移植、人可读）
- **笔记软件**：Obsidian（本地优先、双向链接、图谱视图）
- **AI 助手**：Claude Code / Claude Desktop
- **配置方式**：CLAUDE.md Schema 文件
