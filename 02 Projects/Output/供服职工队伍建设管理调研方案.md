# 一、调研目的及内容

**调研目的**：
供服职工是供电公司管理的最基层、电网的最末端、服务的最前沿，在公司整个人力资源中居于基础地位，承担着重要的职能，发挥着不可替代的作用。2021年以来，省市公司高度重视供服职工队伍建设，创新实行供服职工“六统一”管理，采取优化人力资源配置、盘活存量、拓宽成长通道等一系列措施办法，收到了良好效果。为进一步深入了解“六统一”后公司供服职工队伍建设管理现状，全面真实反映供服职工队伍管理工作中存在的困难和问题，供公司决策参考，6月6日，公司总经理曾小平同志批准由市三新公司牵头、联合市公司人资部组织开展供服职工队伍建设管理现状专题调研。
**调研内容**：

# 二、调研计划
## （一）调研组织
1. 人资部联合发文开展专项调查
2. 走访相关部门，收集关注话题和业务痛点
3. 由人资部召集相关部门分口下达调研配合工作安排
4. 召开各分公司动员会议，宣贯调研方案，明确责任分工、进度计划和纪律要求，方案提前下发各分公司准备
5. 各分公司成立“1+1+3”调研工作组：
- 调研组长：县公司分管领导
- 副组长：分公司负责人
- 组员：
**主调研员**：人资专责（调研报告主笔人）
**副调研员**：培训主管 （访谈记录、上下联络）
**现场调研员**：供电所三新联络员（培训助教）（现场组织、线上收集）
**辅助调研员**：新员工1人 （资料收集整理、数据表格整理）
6. 总公司成立“一拖三”调研专班：
**专班牵头**：程军明
**调研报告主笔人**：龚勇 提纲 内容
**副主笔**：郑琦 资料汇总 会商召集 进度督办
**总联络员**：李曼 数据分析 附件表格整理
7. 认真学习相关文件。收集省市公司“六统一”管理文件，汇编成册，印发给全体调研成员学习，提前熟悉相关政策制度和工作部署，确保每个成员深入了解调研工作内容
## （二）调研对象
### （1）供电所全覆盖
- 按供电地域划分，乡镇所、城区所、偏远所
- 按业务规模分，ABC类
### （2）供服职工全覆盖
- 按典型岗位分类
- 按男女性别分类
- 按年龄段分类
- 按群体分类，供服职工工匠和新员工
 ## （三）调研方法
1. 问卷调查法：设计线上调研问卷
2. 访谈调查法：供电所召集现场访谈
3. 实地观察法：查看现场资料、台账、信息系统
4. 统计分析法：对无系统取数的调查类信息设计统计报表，通过收集数据进行统计分析得出调研结果。
 ## （四）进度安排
### **（1）准备阶段：6月12日-16日**
- 具体工作为设计调查问卷、组织调查员队伍、各分公司排出调查计划、协调供电所时间安排、调查员培训、试调查
- 调查员必须经过半天专门培训，培训内容包括了解调查项目、调查要求、访谈技巧、熟悉问卷、做试访谈、分组和管理要求等。正式实施前，每个主调查员必须完成一份试调查，经过集体总结后才能正式开展调查
### **（2）调查实施阶段：6月19日-7月5日**
- 具体工作为各分公司规划好调研行程路线，每个分公司为一个调查组，下到供电所开展调查，实地与供服职工面对面访谈，所长“一对一”访谈，以结构式访问的方式完成线上实名制调查问卷
- 在县公司召集相关部门座谈、县公司党政主要负责人和分管负责人“一对一”访谈
- 注意发掘供服职工队伍建设特色经验亮点
- 每日9:30前通过腾讯文档线上数据及时汇总进度日报，发现问题及时处理和开展补充调查
- 每周三上午10点视频会商及时纠偏督促推进
- 供电所现场调研（访谈）12个工作日完成
### **（3）资料整理阶段：7月6日-7月12日**
- 为保证收集资料信息质量，各分公司上报资料由总公司负责集中汇总和甄别，进行专门培训，借助数字化工具进行统计分析制表成图
- 各分公司按给定模板撰写本单位调查报告
### **（4）撰写调查研究报告阶段：7月13日-7月28日**
- 拿出整体调研报告初稿，7月21日前完成
- 经与人资部会商后，调研报告初稿7月23日前送领导审阅
- 按领导审阅意见修改形成最终稿，7月28日前送领导参阅
- 根据工作需要呈送公司相关领导参阅
